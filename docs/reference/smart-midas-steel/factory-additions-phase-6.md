## 지원 범위

기존 5개 작업 흐름과 모델링 위저드 6단계를 유지한다. 지역·하중의 **개구부·건물 연결부**에서 필요한 기능만 켠다. 한국·중국·대만 설계기준과 4개 언어를 지원한다. 새 옵션을 선택하지 않은 프로젝트의 기존 모델·정답 결과는 유지한다.

| 기능 | 웹에서 하는 일 | Gen에 반영하는 일 |
|---|---|---|
| 닫힌 지붕 해치·채광창 | 한 지붕면·한 베이의 격자 범위, 보강 H형 단면, 프로젝트 처짐 한계·출처 입력 | 내부 퍼린 제거, 경계 퍼린을 H형 보강보로 교체, 기존 외피 하중을 보강보로 재분배 |
| 플랫폼 바닥 개구부 | 기존 플랫폼 격자와 맞는 내부 범위·베이·출처 입력 | 내부 작은보 제거, 빈 면적의 고정·활하중·지진중량 제외, 기존 테두리보 유지 |
| 건물 연결부 | 두 건물의 이동·온도·오차에 따른 이격·받침 여유 검토 | 고정·이동형에 한해 외부 해석에서 확인한 동시 반력을 현재 공장의 기둥에 전달 |

**외부 건물이나 연결교 전체의 형상·강성·받침을 새로 모델링하지 않는다.** 연결동은 검토와 반력 인터페이스 범위다. 두 건물의 일체형 결합 해석은 지원하지 않으며 해당 모드의 자동 Gen 생성을 차단한다. 추가 구조는 기존과 같이 예비검토 상태를 유지한다.

## 1. 닫힌 지붕 해치·채광창

- 방수 덮개가 닫힌 개구부를 가정한다. 실제 지붕면 내부의 퍼린 격자선 두 개와 한 베이를 선택한다. 두 경계 사이에 적어도 하나의 퍼린이 있어야 한다. 처마·마루·골을 가로지르거나 지붕 가새 베이를 선택하면 차단한다.
- 경계 두 줄은 해당 기준·재료의 Gen 등록 확인 H형 단면으로 교체한다. 내부 퍼린은 제거한다. 횡방향 경계에는 기존 주 지붕보를 유지한다. 덮개가 하중을 양쪽 보강보로 전달한다는 가정이며 별도의 판·다이어프램 강성을 만들지 않는다.
- **덮개의 기존 지붕 고정·활·적설·풍하중 면적을 유지한다.** 제거한 퍼린의 외피 하중은 컴파일용 가상 수집자로 계산한 후, 각 위치에서 두 보강보까지의 거리 비율로 재분배한다. 단일 지붕면의 선형 높이 관계를 이용하여 힘과 전역 모멘트를 보존한다.
- 가상 수집자는 Gen 요소·강재 자중·물량에서 제외한다. 실제 H형 보강보의 자중·지진중량만 추가한다. 기존 지붕 마감 지진중량은 그대로 유지한다.
- 해당 덮개 위의 별도 설비는 자동 적용하지 않으며 충돌 입력을 차단한다. 해치 덮개 내력·접합·정착·국부 풍압 구역 변경·적설 표류·방수·배수는 별도 설계다. **열린 지붕 구멍의 내압·풍압 면적 감소를 자동 적용한 것이 아니다.**
- H형 보강보는 국가별 기존 강도식으로 예비검토한다. 전체 베이 길이를 비지지 길이로 사용한다. 처짐은 앱 단면 근사값과 `5qL⁴/(384EI)`로 **웹에서 추정**한다. 자중과 덮개 D, 지붕 활하중 또는 각 적설 상태를 따로 평가하고 프로젝트 `L/입력값`과 비교한다. Gen의 연속 처짐 회수값이나 전단 변형·덮개 국부 처짐 검토로 표시하지 않는다.

## 2. 플랫폼 바닥 개구부

- 메자닌·설비 플랫폼을 선택했을 때만 표시한다. 플랫폼의 실제 작은보 격자와 일치하는 X 범위 및 한 베이를 선택한다. 플랫폼 바깥 가장자리에 닿는 개구부는 지원하지 않는다.
- 개구부 내부의 길이 방향 작은보를 제거한다. 경계 작은보와 베이 양 끝의 기존 주보는 유지한다. 경계 작은보를 테두리보로 구분하여 표·3D·계산서에 표시한다. 개구부를 가로지르는 새 보나 슬래브를 자동 생성하지 않는다.
- 남아 있는 바닥 스트립의 면하중을 인접 보에 반씩 분담한다. 빈 면적에 해당하는 고정·활하중, 활하중 지진반영분을 제거한다. 제거한 작은보의 강재 자중·지진중량도 제거하며 테두리보의 자중은 한 번만 반영한다.
- 개구부 테두리 단면은 현재 플랫폼 보 단면을 사용한다. 강도와 기존 플랫폼 상대 처짐 검토에 포함하며, 필요한 경우 플랫폼 보 단면을 사용자가 키운다. 별도 슬래브·합성·다이어프램·낙하 방지·난간·계단·접합 상세 설계는 포함하지 않는다.
- 내부 기둥과 박공 풍주가 플랫폼 경계에서 만나는 위치도 실제 격자에 포함한다. 기존 기둥·지붕보·기초를 임의로 삭제하지 않는다.

## 3. 연결동 인터페이스

### 이동·이격·받침의 웹 검토

입력은 건물 A/B의 **동일 방향·동일 재해 수준** 이동 크기, 온도 이동 크기, 시공 오차, 확보 이격, 받침 길이, 최소 잔여 지지 길이다. 출처에는 외부 해석 및 프로젝트 상세의 적용조건을 기록한다.

```text
소요 이동 = |uA| + |uB| + 온도 이동 크기 + 시공 오차
이격 여유 = 확보 이격 − 소요 이동
받침 여유 = 받침 길이 − 최소 잔여 지지 길이 − 소요 이동
```

위 식은 프로젝트의 보수적 검토식이며 국가별 법정 이격 공식으로 제시하지 않는다. 입력은 크기이므로 음수를 허용하지 않는다. 부족한 이격·받침은 수치상 NG로 표시한다. 사용성 표와 계산서의 값·한계는 **mm**로 표시한다.

### 지원 모드

- **고정·이동형 — 반력 연계:** 외부 모델에서 산정한 동시 반력 상태를 최대 8개 입력한다. 전역 X/Y/Z, kN 및 kN·m 단위의 6성분을 그대로 전달한다. 각 행은 하나의 동시 상태이며 서로 다른 위치의 성분별 최대값을 합치지 않는다.
- 입력 위치는 현재 공장의 외곽 기둥과 골조 번호·높이다. 필요 시 기둥 요소를 분할하지만 원래 실물 부재 키와 비지지 길이를 보존한다. 외부 연결부의 부재나 가상의 고정 지점을 만들지 않는다.
- `LK001…` 상태와 프로젝트 중력+반력 조합을 만든다. 계수의 적용 전·후 상태를 출처에 명확히 기록하고 프로젝트 연결 반력계수를 맞춰야 한다. 이미 계수화한 반력에 계수를 다시 곱하지 않으려면 입력 계수를 1로 정한다.
- 반력을 외부 건물이나 연결교의 지진 질량으로 변환하지 않는다. 현재 공장 풍·지진과 연결 반력의 동시성, 양쪽 건물 주기 변화, 받침 마찰·충격·슬라이딩 거동, 상대 변위의 독립 산정은 별도다. Gen에 ELNK·비선형 링크나 실제 슬라이딩 접합을 자동 생성하지 않는다.
- **구조 분리형 — 변위 검토:** 이동·이격만 검토하고 반력·연결 부재·LK 조합을 만들지 않는다. 저장된 반력 입력이 있어도 전송하지 않는다.
- **일체형:** 두 건물의 실제 모델과 결합 조건이 필요하므로 자동 Gen 생성 차단 및 결합 모델 필요 문구를 표시한다. 반력만으로 결합 거동을 대신하지 않는다.

TW 지붕보를 RH 600x300x14x23으로 과대 보완한 중간안은 부재·사용성 NG가 0이었지만, 소성모멘트 Mp 증가로 처마 접합의 기존 8-M30 볼트 상세가 1.320까지 초과했다. 최종안은 지붕보를 RH 606x201x12x20으로 바꿔 부재와 접합을 함께 만족시켰다. 접합 소요량과 전체 골조 재분배를 포함해야 하므로 단면이 클수록 모든 검토가 개선되는 것은 아니다. 중간 NG도 각 실행 증거에 보존했다.

최종 증거는 TW `output/additions-live-20261018014653628/`, CN `output/additions-live-20261018012222409/`, KR `output/additions-live-20261018013922091/`이다. 각 폴더의 `evidence.json`과 `<code>-design.json`에 전체 입력·부재·사용성·접합을 저장했다. 각 실행 후 원본 12개 DB 해시가 일치했다. 5·6단계 최종 6개 결과를 검사한 요약은 `output/addition-strengthening-20261018-summary.json`이다.

재현 명령: `node --import tsx scripts/live-additions.ts --phase6 --strengthened`. `--codes=TW,KR`로 필요한 기준만 재실행할 수 있다. 오프라인에서도 6개 보강 샘플의 입력 유효성, 절점·요소 연결 동일성, 프로젝트 하중·반력·하중계수 유지 및 원본 입력 불변성을 확인했다. 강재 자중·강성·정적 지진중량 변화는 라이브 재해석에 포함된다.

이는 명시적인 검증용 보강 샘플이며 기본 단면이나 자동 최적화를 변경하지 않는다. 수치 NG 0은 기존 예비검토 범위에서의 결과다. 추가 구조의 접합·기초·연결 건물의 결합 거동·회전능력 및 Gen 자체 설계 강도비와의 독립 대조 등 기존 검토 한계는 유지한다.
