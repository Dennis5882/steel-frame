## v1.6.0 재평가 후 보완 (2026-10-17)

- 다경간 내부 기둥 상단 변위를 사용성 회수 목록에 포함했다. 지붕보 처짐은 각 경간의 양쪽 지지점 변위를 부호를 유지해 보간한 기준선에 대해 계산하고, 해당 경간의 L/180을 적용한다(D+LR/SN/SV/SH 포락).
- GB 50017-2017 11.5의 표준 구멍·순단면 공제(d+4), 볼트 간격·끝거리와 12.2.1 블록 파괴, 12.2.3(2) 짧은 거셋 압축 안정, 7.1.1-2 슬롯 강관 순단면, 11.2.2 유효 용접길이를 추가했다. 가새 접합 용접 4줄은 구조화된 물량에도 포함한다.
- 거셋 c=75mm·가새 45도·볼트 2열은 상세 가정이다. 자유단·편심·실제 힘 전달, 접합 강성·회전성능, 기초 정착/콘크리트 파괴는 자동 검증이 완료된 것으로 취급하지 않는다. 전문가 등급을 유지한다.
- 플라이브레이스·새그로드는 `가정 / 설계자 확인 / 없음`으로 기록한다. 없음 선택은 횡지지에 의한 길이·약축 모멘트 감소를 해제한다. CN 가새는 원래부터 전 길이를 쓰므로 교차점 지지 선택은 표시하지 않는다.
- 계산서·DXF·CSV에 지지 조건과 제외 물량을 표시한다. 플라이브레이스·새그로드·클립·교차부 연결재 등은 설계 가정과 별개로 발주 물량에 포함되지 않는다.
- 다경간 24+24m 라이브: 376절점, 19케이스/89조합, 반력 오차 표시 0.000%, 최적화 3회 후 부재 96.064t, 부재·사용성·접합 NG 0, API 오류 0. 미확인 횡지지 및 접합 상세 때문에 전체 상태는 전문가 검토 필요다.


적용일: 2026-10-15, GB 51022-2015 门式刚架 규범 반영 2026-10-16 (원문 KB `COde/CN/knowledge/gb51022-2015`, 표·그림은 `_gb51022_raw/img` 원본 이미지로 대조). 헤더의 설계기준에서 중국(CN)을 선택한다. UI 언어 선택과 설계기준 선택은 독립적이다.

## Gen 연동

- 재료: `GB03(S)`의 Q235/Q345. 모델상 재료명은 Q235B/Q345B, 퍼린·거트는 별도 Q235B.
- H형강·강관: `GB-YB05`. C형강: `GB50018-02`(DB 이름이며 검토 규범의 판본을 뜻하지 않는다).
- 공개 설계 API 문서의 중국 코드는 GB50017-03이다. 2017 설계라고 표시하며 구판 DSTL을 보내지 않도록 CN에서는 DSTL을 생략한다. 부재·접합 검토는 앱의 별도 GB 계산이다.
- 기본 형상: 24×36 m, 처마 8 m. 절점 219, 요소 410, 하중 13, 조합 51. 적설 0 또는 지붕 경사에 따라 케이스·조합 수가 달라진다.
- CN 벽 가새는 온도구획 중앙, 지붕 가새는 양 끝 및 벽 가새 위치에 배치한다. 가새 교차점의 중간지지는 인정하지 않는다. TW 가새 위치는 유지한다.
- 중국 부재력 표는 4개 조합씩 나눠 회수한다. 누락된 부재력·사용성 변위는 오류로 처리한다.

## 적용 범위와 계산 가정

기본 골조는 규칙적인 단층·폐쇄형 금속 외장 门式刚架 공장용이다(GB 51022 1.0.2). 처마 ≤18 m, 스팬 ≤60 m, **평균 지붕 높이 ≤18 m·높이/폭 <1**, 편경사 <30°, 길이 ≤90 m, 경사 ≤1, 감쇠비 0.045–0.05 범위를 검증한다. 다층·온도하중·피로·화재는 포함하지 않는다. 이후 추가된 크레인·플랫폼·닫힌 개구부 등은 [현재 지원 범위](../current-status.md#3-추가-구조의-현재-지원-수준)의 예비검토 경로를 따른다. 열린 큰 개구부 전체를 지원한다는 의미는 아니다. 8/9도는 GB 51022 4.4.2-3 수직지진 케이스 EV 를 추가한다(2026-10-16 이전에는 스팬 >24 m 를 거부했음).

지역별 풍압·적설·지진 지도는 자동 조회하지 않는다. `w0`, 지표조도, 지형계수, `αmax`, `Tg`, `Tx/Ty`, 적설, 중요도 및 기초 재료값을 프로젝트 조건으로 입력해야 한다. 기본값은 예시다. 지붕 활하중은 풍·적설과 동시 조합하지 않는다. 지진 중량은 D+0.5S, 지진 조합 계수는 GB 55002의 G=1.3/Eh=1.4를 사용한다.

- Gen 선형 해석 결과에 부재 및 층 안정 증폭을 적용한다. 고유치 해석·비선형 해석에 의한 주기나 2차 효과를 자동 산정한 것으로 보지 않는다.
- 주각 고정/핀 및 보-기둥 강접 가정으로 K를 계산한다. 접합부의 실제 회전강성은 별도 확인 대상이다.
- 탄성 단면계수, 모멘트 분포계수 1을 사용한다. H형강 판 세장비 초과 시 후좌굴 강도를 인정하지 않고 NG 처리한다.
- C형강 유효폭은 인접 판의 유리한 구속효과를 인정하지 않는 보수적 단면 감소 근사다. 비틀림·휨비틀림 검토도 단면 근사를 포함한다. 외장재의 횡지지를 자동 인정하지 않는다. 새그로드는 입력 개수의 양방향 지지 효과를 가정하므로 실제 상세가 이를 제공해야 한다.
- 국부 풍압은 부재가 걸친 가장 불리한 구역을 전 길이에 적용하며 면적 저감은 인정하지 않는다. C형강으로 통과할 후보가 없으면 압연 H형강도 보조 부재 후보에 포함한다.
- 기둥 상단 변위는 GB 51022 표 3.3.1 h/60 (풍·다우지진 모두, 무크레인·경량 강판 벽). 조문 설명대로 실제 변위는 계산값보다 작다. 거트(L/100)·풍주(L/250) 처짐은 외장재/주골조 풍압의 단순보 식이다(보수적).
- 풍하중은 GB 51022 μw (MBMA 2006 기반, 내압 포함). 종방향 끝 구역은 그림 표기가 a 이나 MBMA·ASCE 7 과 같이 2a 로 보수적으로 둔다. 끝 구역은 양쪽 끝에 함께 적용하고, 부재는 중점이 구역 안이면 그 구역 값이다. 다경간 주골조는 표 4.2.2-1 을 풍상 처마로부터 거리로 적용한다(그림은 단경간뿐).
- 반경간 적설(4.3.5-2)은 1.3D+1.5S 조합에만, 지진 조합의 적설은 균일 0.5S 만 쓴다(중력 대표값). 하중계수는 GB 51022 4.5.3(1.2/1.4)이 아니라 GB 55001(1.3/1.5)을 쓴다(통용 규범 우선).
- 금속 지붕 보 L/180, 퍼린 L/150을 적용한다. 미구현: 변단면(楔形) 부재 7.1.3~7.1.5·부록 A.0.1, 웨브 좌굴후 강도 7.1.1, 9.1.5 퍼린 좌굴계수(3.0/23.9/0.425 — 현재 GB/T 50018 계산값), 활하중 0.3 kN/m²(60 m² 초과, GB 55001 과 충돌 가능 → 0.5 유지).
- 접합부는 자동 예비 치수 산정이다. 10.9 마찰접합, 표준 구멍, 마찰계수 0.40, 접촉면 1개를 가정한다. 주각 앵커는 인장만 담당하고 전단은 마찰+전단키로 전달한다. 재료표 검증 두께는 최대 100 mm이며 그 이상이 필요하면 통과시키지 않는다.
- 콘크리트 파괴·앵커 정착·전단키 정착, 접합부 강성·회전능력·볼트 실제 배치, 가새 거셋 좌굴·강관 순단면·블록전단·용접 상세는 별도 상세 검토가 필요하다. 화면 및 계산서에도 표시한다. 처마 1.2Mp·가새 1.1FyAg는 프로젝트 접합부 용량 포락 가정이다.

따라서 검토의 OK는 구현된 계산 항목의 통과를 뜻한다. 중국 규범의 모든 구조·내진 상세를 포함한 최종 승인이나 접합 상세 완성을 뜻하지 않는다.

## 재현 검증

```sh
node --import tsx scripts/verify-cn.ts
npm run typecheck
npm run build
node --import tsx scripts/live-cn.ts --optimize
```

라이브 스크립트는 키를 표준입력으로 받고 메모리에만 유지한다. 기존 Gen 문서를 자동 저장한 뒤 새 모델을 만들므로 시험용 Gen 세션에서 실행한다. 보고서 HTML·DXF·검토 JSON은 OS 임시 폴더의 `smart-midas-cn-live.*`에 생성한다. `--reuse`는 Gen에 현재 기본 사양과 일치하는 해석 모델이 있을 때만 사용한다.

오프라인 검증은 원문 표의 재료강도·좌굴계수·풍압·스펙트럼 앵커, 순단면적, 순수 휨 LTB, 적설 경사·편적설, 하중 합, 국가별 가새 위치·DB 매핑, 적용 범위 차단 및 TW 하중 15/조합 55 유지를 확인한다.
