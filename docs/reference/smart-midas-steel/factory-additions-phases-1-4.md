# 공장 추가 구조 1~4단계 구현

> 기술 참고 · 현재 기능의 상세 규칙 (v2.3.4 기준 문서 정리, 2026-10-19). 아래 버전별 수치·시험 기록은 해당 시점의 결과입니다. 현재 지원 상태는 [현황](../current-status.md), 남은 과제는 [로드맵](../roadmap.md)을 우선 확인하세요.

2026-10-17 · v2.0.0

## 적용 범위

기존 작업 흐름 5개와 모델링 위저드 6단계를 유지한다. 시작·범위에서 크레인 또는 메자닌을 선택하면 **지역·하중** 단계에 해당 입력을 표시한다. 지붕 설비는 같은 단계에서 개별 추가한다. 언어와 설계기준은 독립적이다.

이번 구현은 **추가 구조의 해석·예비검토**다. 플랫폼을 포함하는 건물을 기존 단층 공장 규정만으로 최종 적합 판정하지 않는다. 입력 확인 후 생성할 수 있지만, 추가 구조가 있는 모델의 부재·전체 상태에는 전문가 검토 사유가 남는다. 샘플 단면의 NG는 그대로 표시한다.

| 단계 | 구현 |
|---|---|
| 1. 공통 기반 | 좌표 기반 실물 부재 키, 해석 요소와의 대응, 원래 횡지지 길이 보존, 하중·지진중량 출처별 원장 |
| 2. 설비 | 지붕 설비별 위치·중량·지진중량 반영률·출처 입력, 주변 지붕 절점으로 하중 분배 |
| 3. 크레인 영향 | 제조사 최대/최소 차륜하중, 차륜 간격, 충격계수, 횡력·제동력, 편심 모멘트, 정적 임계위치별 골조 반력 |
| 4. 플랫폼 | 부분 평면 범위, 설치 높이, 보 격자·기둥, 기존 수직 부재와의 교차 연결, 바닥 하중, H형강 선택·예비검토 |

5단계의 주행보 예비모델·닫힌 측벽 출입문은 이후 v2.1.0에서 추가했다. [5단계 구현 문서](factory-additions-phase-5.md)를 참고한다. 6단계(지붕·바닥 개구부·연결동)는 별도로 진행한다. 아래는 v2.0.0 당시의 범위와 검증 기록이다.

## 입력과 검증

- 추가 하중마다 출처를 기록하고 확인해야 생성할 수 있다. 형상·재료 등 기존 입력을 수정하면 추가 항목 확인을 해제한다.
- 크레인 최대/최소 값은 **차륜당 충격 적용 전 하중(kN)**이다. 정격 인양능력을 차륜하중으로 변환하지 않는다. 수평력은 크레인 전체 합계다.
- 크레인 1대·레일당 2차륜이다. 초기 8베이 계산량 제한은 이후 제거했다. 현재 운행 범위는 건물 전체가 기본이며 일부 베이만 지정할 수도 있다. 차륜 간격은 선택한 운행 구간의 길이보다 작아야 한다.
- 플랫폼의 시작·끝은 화면에서 1부터 세는 **골조 번호**로 지정한다. 내부 데이터는 0부터 세는 경계 인덱스다. 실제 불균등 베이 좌표를 사용한다.
- 플랫폼 단면은 해당 설계기준·재료의 Gen 등록 확인 카탈로그에서 선택한다. 격리 단면·재료 비지원 단면은 제외한다. 검토 표시는 Gen DB 성능과 앱 근사 성능의 차이를 별도 확인해야 한다는 뜻이다.
- 하중계수와 사용성 한계는 **프로젝트 적용값**이다. 초기 제안값을 모든 용도에 적용되는 법정 값으로 표시하지 않는다. 근거와 확인이 필요하다.

## 모델·하중 처리

### 실물 부재와 해석 요소

추가 접합 높이에서 기존 기둥·풍주를 분할하고, 실물 부재 키와 원래 요소의 횡지지 길이를 유지한다. 단순히 절점이 생겼다고 좌굴·횡비틀림 지지점으로 인정하지 않는다. 플랫폼 보의 내부 해석 절점에는 핀을 넣지 않고 실물 보의 끝만 해제한다. 처짐 확인을 위해 작은보 중앙에 결과 절점을 만든다.

기존 수직 부재가 있는 위치에서는 그 부재에 연결한다. 같은 축에 신설 기둥을 겹치거나 기존 핀 기초를 신설 기둥의 고정 기초로 바꾸지 않는다. 기존 수직 부재가 없는 플랫폼 가장자리에는 독립 고정 기초 기둥을 만든다.

### 하중·지진중량

- 지붕 설비는 주변 지붕 지지점에 분배하며 수직력과 평면 위치 모멘트를 보존한다. 설비 정착·지붕 국부 지압은 별도다.
- 플랫폼 면하중은 작은보의 분담 폭으로 선하중화한다. 구조 자중은 Gen 자중에서 한 번만 재하한다.
- 지진중량 원장은 설비 반영률·플랫폼 고정하중·활하중 반영률·추가 강재 자중·크레인 지진중량을 추적한다. 기존 정적 등가 지진하중 생성에 반영한다.
- **Gen 모달 질량(NMAS/LTOM) 또는 응답스펙트럼 해석을 새로 구현한 것은 아니다.** 내진 시스템·주기·수직 분포·비틀림의 적합성은 추가 구조가 있는 프로젝트에서 별도 검토해야 한다.
- 크레인 차륜하중에는 장비 자중이 포함된 것으로 입력한다. 크레인 지진중량을 별도 D 하중으로 다시 재하하지 않는다.
- 바닥 활하중이 들림·모멘트 반전에 유리하게 작용할 수 있으므로, 기존 조합은 활하중 0 대안으로 유지하고 동반 활하중을 더한 조합을 별도로 만든다. 짧은 `AP…` 이름에도 원 조합의 횡력 방향과 일반/증폭/중력 분류를 보존한다. 원 조합 이름은 Gen 조합 설명에 기록한다.

### 크레인

단순지지 레일의 반력 분배를 이용한다. 각 차륜이 골조선에 도달하는 위치와 양 끝 위치에서 최대 레일 방향 및 수평력 부호별 동시 부재력을 유지한다. 편심은 기둥 축 절점의 모멘트로 전달한다.

현재 추가 조합은 중력+크레인 및 D 감소 조합이다. **풍·지진과 크레인의 동시 조합, 복수 크레인, 인양·제동 운전 조건별 관계, 피로·충격 반복, 주행보·레일·브래킷 상세는 포함하지 않는다.** 정적 골조 영향 검토에 대한 범위이며, 완전한 크레인 건물 설계로 표시하지 않는다.

### 플랫폼

슬래브·합성 효과·다이어프램 효과 없는 보 격자다. 추가 H형 부재는 해당 국가의 기존 강도식으로 예비검토하며, 실물 부재 전체 비지지 길이를 사용한다. 독립 고정 기둥의 예비 좌굴 길이는 2L이다. 전체 골조 안정성 및 접합 강성의 적합성은 별도다.

사용성은 D+PL의 지지점 대비 상대 처짐, D+각 크레인 케이스의 지지점 수평변위를 프로젝트 한계와 비교한다. 절점 기반 처짐이므로 모든 위치의 연속 처짐 극값을 구한 것은 아니다.

## 결과·산출물

- 추가 부재를 지붕 퍼린·벽 거트 하중 및 기존 접합 자동 설계에서 분리한다.
- 추가 플랫폼 부재의 단면은 개별 입력값으로 유지한다. 기존 주골조 최적화 과정이 이를 스트럿·풍주 단면으로 덮어쓰지 않는다. 추가 부재의 자중은 최적화 물량에 고정분으로 포함한다.
- 물량은 실물 부재 키로 개수를 세고 실제 단면으로 중량을 합산한다. 추가 접합재·기초·설비 정착·주행보는 산출 범위에서 제외한다.
- 계산서에 입력 출처, 적용계수, 지진중량 원장, 추가·분할 실물 부재의 요소 대응 및 예비검토 범위를 기록한다. 전체 대응은 모델 메타데이터에 유지한다.
- DXF·계산서 도면에 S6 추가 구조 평면, S7 추가 구조 입면을 제공한다. 플랫폼을 S1 지붕 골조 평면에 섞지 않는다. 시공 상세 도면은 아니다.

## 검증

오프라인 검증은 `node scripts/verify-all.mjs`, 빌드는 `npm run build`로 수행한다. 새 `verify-additions.ts`는 3개 기준의 힘·모멘트 보존, 바닥 분담 면적, 자중·지진중량 중복 방지, 실물 길이·단부 해제, 데이터 누락 및 출처 확인 차단, 추가 도면을 점검한다. PDF 검증은 기존 3개 기준과 추가 구조 예시를 4개 언어로 생성하고 글리프를 검사한다.

라이브 명령은 `node --import tsx scripts/live-additions.ts`다. 키는 `.env`에서 읽고 출력하지 않는다. 현재 문서를 별도 파일로 저장한 뒤 시험하고, 종료 시 원본을 다시 열어 12개 DB 해시를 대조한다. 시험 중 발생한 0 하중 절점 레코드 거부는 전송 제외로 수정했다.

### 최종 검증 기록

오프라인 **21개 검증 묶음 통과**, 추가 구조 전용 **4,359개 검사 통과**, TypeScript·배포 빌드·4개 언어 릴리즈 노트 검사 통과. 기존 TW/CN/KR 정답 모델 결과를 유지했다. 추가 구조 계산서와 기존 3개 기준 계산서를 4개 언어로 PDF 생성해 글리프를 검사했고, 추가 입력표·실물 부재 표·S6/S7을 렌더링해 확인했다.

브라우저에서는 옵션 선택 후 6단계 이동, 미완료 그룹으로 포커스 이동, 소수 입력, 개별 설비 추가, 출처 확인 후 최종 단계 진입, 4개 언어 전환 시 값 유지, 스팬 변경 시 추가 항목 4개의 확인 해제를 점검했다. 유효한 형상·하중의 미리보기는 출처 확인 전에도 갱신하며 Gen 생성만 확인 전 차단한다.

최종 Gen 시험은 2베이(5+7 m), 지붕 설비 40 kN, 크레인 1대, 부분 플랫폼을 함께 적용했다. 수치 아래의 ‘통과’는 모델 전송·해석·전체 부재력/변위 회수·데이터 완전성·반력 평형 확인을 뜻한다. **샘플 단면에는 NG가 있으며 설계 적합 통과를 뜻하지 않는다.** Gen 자체의 강구조 코드체크와 앱 강도비를 독립 대조한 시험도 아니다.

|---|---:|---:|---:|---:|---:|---|

| CN | 158 | 262 | 34 | 223 | 0.0008% | 통과 |

반력 평형은 Gen 반력 표의 소수 3자리 출력과 전송 선·절점 하중을 비교했다. D는 Gen DB 단면/재료 기반 자중이 포함되므로 위 비교에서 제외했다. 앱의 단면 근사와 Gen DB 성능의 차이는 기존 카탈로그 검토 표시로 유지한다.
