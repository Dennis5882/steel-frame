### 원문 이미지 확인

PDF 물리 페이지 70의 6.2-39는 `[45360(1−ξweb)+62160]` 전체에 `(L/ho)²`가 곱해진다. 구조화 텍스트만 읽으면 대괄호 범위를 오해할 수 있어 원본을 렌더링해 확인했다.

PDF 물리 페이지 107의 7.3-13은 압축 임계 파장 식 첫 항을 **Iyf**로 표기하지만, 7.3-10이 참조하는 회전강성 응력식에는 **Ixf**가 쓰인다. `twDistortional.ts`는 인쇄된 파장을 보관하고, 응력식에서 직접 유도한 정상점 파장도 함께 평가해 더 낮은 응력을 적용한다. 응력식이 `a/L² + b + cL²` 형태이므로 그 최소점은 `L⁴=a/c`이며, 이 계산은 다른 국가 규범의 파장식을 가져온 것이 아니다. 원문 정오표/공식 판본 확인은 추가 검증 대상이고 이 보수적 처리도 계산서에 명시한다.

## 예비검토를 유지하는 이유

원문을 받기 전의 ‘원문 미대조’ 문구를 ‘제한적 검토’로 수정했다. 다음 항목이 남으므로 냉간 부재를 일반 통과 등급으로 올리지 않았다.

- 약축 휨은 총단면 Sy를 사용하며 약축 압축판의 유효폭을 아직 반영하지 않는다.
- 하중 작용선과 전단중심의 편심 비틀림(6.7)을 검토하지 않는다.
- 지점 반력에 대한 웨브 지압·휨 조합(6.5~6.6)은 지압길이·실제 지점/보강 조건 입력이 필요하다.
- 클리트·볼트 구멍의 순단면 파단·연결 상세를 자동 설계하지 않는다.
- 재료 품질증명·연신율 및 실제 지지 상세를 자동 인증하지 않는다.

이 항목은 현재 원문 검토에서 확인한 후속 구현 과제다. 규범 전체 구현·제작 승인·발주 상세 완료로 해석하지 않는다.

## 검증과 재현

`node --import tsx scripts/verify-tw-coldformed.ts`: 22개 검증. 유효폭 무차원 고정점, 뒤틀림 강도식과 원문 전사 수치·응력식 정상점, 인장·휨 두 연단, 휨·전단 분모, 치수·재료 한계, 압축 Q 및 실패 등급 연결을 포함한다.

`verify-tw.ts --update`는 기존 Gen 원시 부재력·변위·입력은 유지하고 기대 검토값만 갱신했다. 기존 410부재 기준 모델은 최대비 0.912207, 수치 NG 0이다. 이는 해당 모델의 회귀 결과이며 남은 냉간 상세를 검증한 결과가 아니다.

작업 시작 HEAD와 대조하면 TW 부재의 지배 기록 284개(강도비 변경 221개, 최대 절대 변화 0.033978)가 바뀌었다. 식 번호 변경과 유효 강도 변화가 포함된다. TW/KR/CN 모두 입력·원시 결과·반력은 동일함을 확인했으므로 새 해석 결과를 과거 기준 모델의 정답으로 혼합하지 않았다.

최종 공통 품질 게이트는 `npm run verify`와 `npm run build`다. 한국·중국 기준 모델도 함께 검사해 국가별 분기 영향을 확인한다.
