## Gen 연동 (라이브 확인 2026-10-16)

연동명은 `wg_api_framework.dll` 문자열에서 찾았고, 라이브에서 모두 수용됐다(박공·편경사·다경간, API 오류 0).

라이브에서 발견해 고친 것:
- 가새(TRUSS)에는 보 하중을 넣을 수 없다("Beam Loads cannot be entered"). 가새 가상하중은 양 끝 절점에 반씩 절점하중으로 보낸다.
- 한 절점에 같은 하중 케이스 항목이 둘 이상이면 Gen은 하나만 남긴다. 같은 케이스는 합산해서 보낸다(회귀 검사 포함).
- 하중조합 이름은 20자 이하. 조합 이름에서 `KDS ` 접두사를 뺐다(최대 17자).
- Gen KDS 설계: DSTL 지정 뒤에는 재해석이 필요하고, 강재 설계용 조합 `db/LCOM-STEEL`(STRENGTH)이 없으면 `CODE-ANAL`이 `failed:LoadCombination`을 낸다.

- 재료: `STANDARD 'KS22(S)'`, DB = 강종명(SS275, SM355 …). 퍼린·거트는 MATL 2(SS275)로 보낸다.
- 단면 DB `KS21`: `H 600x200x11/17`, `LH 150x75x3.2/4.5`, `P 139.8x4.5`. LH의 SHAPE는 `H`로 가정했다.
- 강재 설계 코드는 구 `db/DSTL`이 아니라 `DESIGN/STEEL/DSTL`(`KDS 41 30 : 2022`, MIDAS API 매뉴얼 25장)이다. 모델 생성 때는 보내지 않고, 라이브 대조 `--gen-check`에서만 설정한 뒤 `CODE-ANAL`(60 s 제한) → `post/STEELCODECHECK`.
- 가상하중 케이스(NXD…)의 STLD TYPE은 `USER`다.
- KS21에는 립 C형강 45개가 `LC-150x65x20x3.2` 형식으로 있다(SHAPE `CC`, 라이브 수용 2026-10-16). 처음에 하이픈 이름을 추출에서 놓쳐 '없음'으로 잘못 기록했었다. 냉간성형 강재 `SSC275`(KS22(S))도 수용된다.
- 기본 퍼린 `LC-200x75x20x3.2`, 거트 `LC-150x75x20x3.2`, 2차 재료 SSC275.

## 외장재설계용 풍하중 (2026-10-16)

퍼린·거트는 주골조 풍압(해석 부재력)과 외장재 풍하중 중 불리한 쪽으로 검토한다. KDS 1.2 용어 정의에 따라 외장재 풍하중은 이를 지지하는 퍼린·거트에도 적용된다.

- 식 5.4-3: p = q_H(Ĉpe − Ĉpi). q_H는 조도 A·B·C이면 C로, D이면 D로 계산한다(5.4.2(1)). |p| ≥ 0.675 kN/m²(5.4(2)).
- 피크외압계수: 표 5.8-2(박공 벽·지붕), 5.8-3(편지붕), 5.8-4(다중박공). 원문 그래프 그림을 직접 읽어 로그 면적 직선 보간했다.
  - 벽 정압은 그림상 2 m²까지 평탄해서 2 m²부터 줄인다(전사본은 1 m² — 보수적으로 2).
  - θ ≤ 10°이면 벽 값을 10% 줄인다(표 5.8-2① 주 3).
  - θ ≤ 30° 박공 지붕은 정압 그래프가 없다 → 정압 Ĉpe = 0이고 내압만 작용한다.
- 피크내압계수(표 5.8-9)는 주골조 표 5.7-4의 정확히 2배다(같은 밀폐 분류).
- 유효수압면적 = 경간 × 부담폭(용어 정의 '하중분담 표면적'). 대만식 L/3 하한은 쓰지 않는다.
- 구역 폭 a = min(0.1·최소폭, 0.4H) ≥ max(0.04·최소폭, 1 m). 부재가 걸친 가장 불리한 구역을 전 길이에 적용한다.
  - 박공·다중박공 θ > 10°는 용마루 양측 띠도 ②. 다중박공 θ > 10°는 경간마다 구역을 나눈다.
  - 편지붕은 방향 구분(② vs ④, ③ vs ⑤)을 생략하고 가장자리 띠 2a = ④, 모서리 2a × 4a(양방향) = ⑤로 보수적으로 단순화했다.
- 조합: 정압 1.7-3(1.2D + 1.6(Lr 또는 S) + 0.5W, 퍼린만)·1.7-4(1.2D + 1.0W + 0.5(Lr 또는 S)), 부압 1.7-6(0.9D + 1.0W). 단순보 Mx = wL²/8.
- 플랜지 구속: 정압이면 외장재 쪽 플랜지 압축(구속, L_b ≈ 0), 부압이면 자유 플랜지 압축(L_b = 새그로드 간격, C_b 1.0).
- 적용범위: 기준높이 H ≥ 20 m(표 5.8-1)와 편지붕 θ > 30°(표 없음)는 막는다(`validateKrSpec`).
- 샘플(밀폐, `wallsLeaky`): 외장재 하중이 퍼린 54개의 지배 조합이 됐지만 최대 강도비는 0.546으로 거의 같다. KDS 주골조 풍압의 G_D(2.08)가 커서 주골조 쪽이 더 불리한 경우가 많다. 탁월 개구부(`dominant2`)에서는 외장재 하중이 지배한다(회귀 검사).

## 접합부 (KDS 14 31 25, 2026-10-16)

TW·CN과 같은 결과 형식으로 주각·처마·마루·가새를 자동 산정한다.

- 볼트 F10T: Fnt 750·Fnv 400(나사부 포함), φ 0.75, 인장+전단 4.1-8(20% 이하면 무시). 가새는 마찰접합(μ 0.5, 표준공 φ 1.0, T0 표 4.1-10).
- 지압 1.2Lc·t·Fu ≤ 2.4d·t·Fu, 필릿 φ 0.75·0.6FEXX·0.7s·(L − 2s) — KDS 유효길이는 전체 − 2s(AISC와 다름). 용접봉 420(400 MPa 급)·490.
- 콘크리트 지압 φc 0.65, √(A2/A1) ≤ 2. 앵커 강재는 볼트와 같이(4.6 = Fnt 300·Fnv 160).

## 지진력저항시스템·내진상세 (KDS 41 17 00 표 6.2-1 · KDS 14 31 60, 2026-10-16)

입력 「X/Y 방향 지진력저항시스템」. 기본은 일반규정만(R 3·Ω0 3·Cd 3, 범주 D 60 m까지).

## 냉간성형 립 C형강 (KDS 41 30 30, 2026-10-16)

KDS 41 30 30 = AISI S100-16 번역(유효폭법). 유효폭·립 보강 플랜지는 TW 루틴(`twColdFormed`)을 재사용하고 φ와 조합식을 KDS로 바꿨다.

- 휨 φb 0.90: Mne(횡비틀림, 4.4-6), Mnℓ = Se(Fn)·Fn, **단면형상변형 Mnd**(4.4-44·45, Fcrd 4.13-32, 표 4.13-1 플랜지 성질). k̃φwe는 KB 누락 → AISI S100-16 2.3.3.3-6. 4.13-11 분모는 합(KB 전사 오류).
- 압축 φc 0.85: Pne·Pnℓ·Pnd(4.3-22~25). 인장 φt 0.90. 전단 φv 0.95.
- 조합: 압축+휨 4.6-4 선형(B1 = 1/(1 − Pu/Pe)), 인장+휨 4.6-1·4.6-2, 휨+전단 4.6-5.
- 보수적 단순화: β 1.0, kφ 0(외장재 회전강성 미고려), Lm = 새그로드 간격. 처짐은 유효 I(4.10.1, 응력 Fy).
- 표 1.6-1 적용 한계 밖이면 메모. TW `CC`(원문 미대조 → 예비검토)와 달리 KR 립 C는 원문 대조 완료라 등급을 낮추지 않는다.
- 표 4.13-1 플랜지 성질은 선요소 직접 적분으로 회귀 검사(verify-kr ⑨).
- Gen KDS 강재 검토(STEELCODECHECK)는 립 C 부재를 검토하지 않는다(라이브: 410개 중 246개만 결과).

## 계산 가정 (계산서 10장에도 표시)

**지진구역계수**
- Z(I 0.11 / II 0.07)·지진구역은 KDS 17 10 00 (2024) 표 4.2-1·4.2-2다(KB 추가 2026-10-16, 이전 통상값과 일치). S = Z × I, I = 2,400년 2.0(4.2-2, 41 17 00 3.2).
- 입력 「행정구역」을 고르면 지진구역·S가 채워진다(강원은 시·군별 — 남부 7 = I, 북부 11 = II). 구역과 행정구역이 다르거나 S < 0.8·Z·2.0이면 실행을 막는다(41 17 00 3.2 국가지진위험지도 하한).
- 지반증폭계수(S2~S5)는 KDS 17 10 00 표 4.2-8과 같다(회귀 검사).
- S = Z × 2.0이며 입력에서 고칠 수 있다.
- 기본풍속 V0(그림 5.5-1)와 지상설하중 S_g(그림 4.2-1)는 KDS 41 12 00에 등치선 지도로만 있고 지역별 표가 없어 자동 입력하지 않는다(지도 값을 입력). 샘플은 서울 예시값이다.

**풍**
- G_D는 강체(n_D > 1 Hz)만 다룬다. 근사주기 Ta ≥ 1 s이면 막는다.
- G_pe의 지붕보 고유진동수는 단순보 근사다. 실제 골조보다 진동수가 낮으므로 보수적이다.
- 다경간(θ ≥ 10°)은 표 5.7-1에 다경간 지붕 표가 없다.
  - 첫 풍상면에는 풍상 표를, 나머지 면에는 풍하 표를 적용한다.
  - 이 때문에 경고 `multiKR`을 낸다.
- 불균형 적설 4.5.3에서 처마 쪽 면은 0.5S_f로 가정했다.

**설하중 최소값**
- 4.3.5(2)를 문자 그대로 적용한다.
- θ ≤ 15°이고 S_g ≤ 1.0이면 최소 설하중은 max(I_s·S_g, 1.0)이다.
- 그래서 서울 샘플의 설하중은 1.0 kN/m²이다.

**조합 축소**
- 대칭 골조에서 거울상 조합은 생략한다(좌우·길이 대칭일 때만).
- 지진 조합의 적설은 균형 적설만 쓴다.
- 1.7-2는 1.7-3에 포함되므로 생략한다.

**사용성 — 프로젝트 기준**
- KDS에는 수치 한계가 없다.
- 지붕보·퍼린: L/240 (L_r 또는 S).
- 풍 횡변위: H/150 (0.65W, 재현기간 50년).

**강도**
- 인장은 총단면 항복만 검토한다. 유효순단면 파단은 2단계 접합부 검토에서 다룬다.
- 웨브가 세장한 H는 미구현이며 NG로 처리한다. 후보 단면에는 해당 단면이 없다.
- B2 > 1.5이면 유효길이법 조건 밖이므로 골조 부재 주석에 표시한다.
