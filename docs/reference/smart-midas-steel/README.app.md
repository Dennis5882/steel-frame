# Smart MIDAS Steel

MIDAS Gen과 연동되는 강구조물(Steel Structure) 자동 모델링 도구.

문서는 [문서 색인](docs/README.md)에서 확인한다. 현재 v2.3.4의 지원 범위·제한·검증은 [구현 현황](docs/current-status.md), 앞으로 할 일은 [개선 로드맵](docs/roadmap.md)에 정리했다. 완료된 계획·시점별 검증은 [아카이브](docs/archive/2026-10-19/README.md)에 보존한다.

표준단면은 국가별 **Gen NX DB 성질**을 웹 검토·자중·물량·단면 제안에 공통 적용한다. 808개 추출 중 800개를 사용하고 미해결 8개는 제외한다. 직접 입력의 치수 기반 계산과 냉간성형 유효단면 예비검토는 구분한다. [출처·검증 기록](docs/reference/gen-section-property-source.md).

모델링은 **시작 → 횡단면 → 길이·베이 → 재료·단면 → 추가 구조 → 지역·하중 → 최종 확인** 7단계다. 추가 구조의 위치·단면·개별 하중은 한 단계에서 설정하고, 다경간과 건물 연결부는 분리한다. [화면 흐름·검증 기록](docs/reference/modeling-additional-structures-ux.md).

v2.3.2의 국가별 기본 골조·추가 구조·단면 보완 라이브 결과는 [Gen NX 검증 기록](docs/archive/2026-10-19/live-validation-v2.3.2.md)에 정리한다. 연동 성공과 시험 단면의 부재·사용성·접합 판정은 구분한다.

## 1. 개요

- **목적**: MIDAS Gen 고객사에게 제공하는 강구조물 모델링 지원 제품
- **연동 대상**: MIDAS Gen
- **연동 방식**: MIDAS Civil/Gen API (MAPI)
- **실행 형태**: 웹 애플리케이션

브라우저에서 `midas-nx` SDK로 Gen NX MAPI를 직접 호출한다. 사용자는 Gen NX의 API 설정에서 발급한 키와 연결 주소를 앱 설정에 입력한다.

현재는 공장 골조의 **모델 생성 → 하중 → 해석 → 부재·사용성·접합 검토 → 단면 최적화 → 계산서 HTML/PDF·DXF** 흐름을 지원한다. 프로젝트 시작 화면에서 대만(TW)·중국(CN)·한국(KR) 설계기준을 선택하며, 언어와 설계기준은 독립적으로 설정한다.

v2.0.0부터 지붕 설비, 크레인의 골조 영향, 메자닌·설비 플랫폼을 선택적으로 추가할 수 있다. 실물 부재·하중 출처·지진중량을 추적하며, 추가 구조는 **예비검토**로 표시한다. 내진시스템·접합·기초 검토와 주행보·브래킷 상세는 별도다. 입력 방법·한계·검증 결과는 [추가 구조 1~4단계 구현 문서](docs/reference/factory-additions-phases-1-4.md)를 참고한다.

v2.1.0은 **주행보 단순보 모델·정적 차륜 재하·상대 처짐**과 **가새 없는 측벽 한 베이의 닫힌 출입문**을 추가한다. 주행보·상인방 단면을 선택하고, 거트 제거·하중 전달·3D·물량·S8 입면에 반영한다. 피로·국부지압·횡전단·비틀림·문 개방 시 내압·접합 상세는 별도 검토다. [5단계 구현 및 검증](docs/reference/factory-additions-phase-5.md)을 참고한다.

v2.2.0은 **닫힌 지붕 해치·채광창 보강**, **플랫폼 바닥 개구부**, **건물 연결부 이동·이격·받침 검토 및 외부 반력 연계**를 추가한다. 지붕 덮개의 하중 면적은 유지하고 바닥의 빈 면적은 하중·지진중량에서 제외한다. 외부 건물·연결교의 전체 모델이나 일체형 결합 해석은 포함하지 않는다. [6단계 구현 및 검증](docs/reference/factory-additions-phase-6.md)을 참고한다.

v2.3.0은 **NG 원인 진단 → 국가별 보완 단면 선택 → 조합 예상값 검토 → Gen 재해석 → 전후 비교**를 제공한다. 기둥–지붕보·스트럿–가새를 함께 검토하고 플랫폼·주행보·개구부 부재도 별도로 보완할 수 있다. 후보는 기존 부재력과 강성비 기반 예상이며, 실제 자중·재분배는 재해석 확인값으로 구분한다. [NG 단면 보완 구현 및 검증](docs/reference/ng-section-remediation.md)을 참고한다.

중국 구현의 근거 조항·적용 범위·검증 방법은 [중국 기준 구현 문서](docs/reference/china_code_implementation.md)를 참고한다. 중국은 GB 50017-2017 및 GB/T 50018-2025의 별도 검토 경로를 사용한다. 입력 기본값은 예시이며, 접합부 결과에는 별도 상세 검토 항목이 남는다.

## 2. 주요 기능 범위

1. **부재(기둥/보) 자동 생성**
   - 격자/층 정보를 입력받아 강구조 부재를 자동 배치·생성
2. **접합부(연결) 설계/체크**
   - 접합부 상세 설계 및 검토
3. **단면/재질 라이브러리 관리**
   - 강재 단면 및 재질 속성 관리
4. **해석 결과 후처리/보고서**
   - MIDAS Gen 해석 결과를 받아 보고서·검토 자료 생성

## 3. 개발 환경

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입체크 + 빌드
```

- 스택: Vite + TypeScript + React + Tailwind v4 + shadcn/ui (참고: story 프로젝트)
- 브라우저가 로컬 MIDAS Gen의 MAPI를 `midas-nx` SDK로 직접 호출

## 4. 사용 대상

- 고객사 / 외부 제공용 제품 (MIDAS Gen 사용자)
