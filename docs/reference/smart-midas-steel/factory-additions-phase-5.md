## 구현 범위

1~4단계의 설비·크레인 골조 영향·플랫폼 위에 선택 기능을 추가한다. 기존 작업 흐름과 모델링 6단계는 유지하며 지역·하중에서 상세 입력을 받는다. 한국·중국·대만 설계기준 및 4개 언어를 지원한다. **예비검토**이며 자동 최종 적합 판정으로 바꾸지 않는다. 6단계인 지붕·바닥 개구부와 연결동은 포함하지 않는다.

이 문서는 v2.1.0 당시의 기록이다. 이후 v2.2.0의 닫힌 지붕 해치·바닥 개구부·건물 연결부 검토 범위는 [6단계 문서](factory-additions-phase-6.md)를 참고한다.

## 주행보

- 기존 크레인 입력에서 **주행보 모델**을 켜면 해당 재료·설계기준의 Gen 등록 확인 H형 단면과 프로젝트 처짐 한계, 근거 및 확인을 입력한다. 끄면 1~4단계의 골조 반력 모델을 유지한다.
- 초기 최대 4베이 계산량 제한은 제거했다. 건물 전체 또는 지정한 시작·끝 베이 안에서 실제 불균등 기둥 간격을 사용한다. 결과 표는 조합별로 나눠 회수하며 차륜 샘플은 유지한다. 기존 거트와 같은 높이에 부재를 중복 생성하지 않도록 그 높이는 차단한다.
- 양쪽 기둥 축상에 베이별 단순지지 보를 만든다. 차륜 위치와 중앙에 결과 절점을 만들되 실제 경간의 양 끝만 회전 해제한다. 중간 절점을 횡지지나 핀으로 취급하지 않는다. 강도 검토의 비지지 길이는 실물 경간 전체다.
- 차륜하중은 해당 위치의 주행보 절점에 한 번만 재하한다. 기존 반력을 추가로 중복 재하하지 않는다. 편심의 등가 모멘트는 기존 단순지지 반력 분담으로 기둥에 전달한다. 실제 레일 축·브래킷의 입체 형상을 만든 것은 아니다.
- 차륜과 지지점의 일치 위치 외에 경간 내부·중앙 및 두 차륜에 대한 휨 검토 위치를 추가한다. 각 위치의 동시 부재력을 유지한다. **모든 연속 이동 위치의 완전한 포락선은 아니다.**
- 국가별 기존 H형 부재 강도식을 사용한 축력·이축 휨·강축 전단 예비검토를 수행한다. **횡전단·비틀림·차륜 국부지압·웹 크리플링·피로·레일과 브래킷·접합 상세는 검토 범위 밖**이다.
- 사용성은 `D + CR…`의 지지점 변위를 선형 보간한 기준선에 대한 상대 수직 절점 처짐을 프로젝트 `L / 입력값`과 비교한다. 입력 차륜 충격계수도 포함한다. 프로젝트 기준이 요구하는 비충격 운전하중 처짐·수평 처짐·레일 간 상대변형은 별도 검토한다.
- 원래 크레인 지지점 수평변위 검토는 실제 골조선의 지지점만 사용한다. 주행보 중간 결과 절점을 지지점으로 포함하지 않는다.

## 벽 출입문

- **측벽 한 베이 전체 폭, 지면부터 기존 거트 높이까지의 닫힌 출입문 1개**를 지원한다. 측벽 `X=0` 또는 `X=전체 폭`, 베이, 거트 높이, H형 상인방, 출처·확인을 입력한다.
- 베이 드롭다운은 실제 폭을 표시하고 가새 베이를 비활성화한다. 모델 생성 시에도 동일하게 차단한다. 가새를 옮기거나 삭제하지 않는다.
- 기존 골조 기둥을 문설주로 사용한다. 개구부 안의 거트를 제거하고 상단에 H형 상인방을 연결한다. 기존 기둥의 베이스 조건과 원래 비지지 길이는 유지한다. 출입문 범위를 막는 플랫폼, 주행보와 같은 높이의 상인방 등은 차단한다.
- **닫힌 문의 압력 면적을 유지**한다. 하부 거트가 받던 고정하중·풍하중 띠를 같은 높이의 양쪽 문설주에 등가 절점하중으로 전달하고, 상단 띠는 상인방에 전달한다. 전체 힘·전역 모멘트를 보존한다. 문 및 외벽 중량은 입력한 벽 마감 고정하중을 동일하게 적용하는 가정이다.
- 제거한 거트는 하중 컴파일용 가상 수집자로만 사용한다. Gen의 요소·자중·물량에 포함하지 않는다. 가상 수집자의 면 마감 중량은 지진중량에 유지하며 거트 강재 중량은 제거한다. 실제 상인방 강재 자중과 지진중량은 한 번만 추가한다.
- TW는 폐쇄형, KR은 모든 면 밀폐 또는 벽면 틈새·지붕 밀폐 조건으로 제한한다. CN도 닫힌 외피 조건만 지원한다. **문을 열었을 때의 지배 개구부·내압 변화나 풍압 면적 감소를 자동 적용하지 않는다.**
- 부분 베이 문, 별도 문설주, 문 하드웨어·레일·정착, 개폐 동하중, 상인방 사용성 한계에 따른 자동 검토는 포함하지 않는다. 비대칭 개구부에 따른 반대 방향 풍하중·전체 안정성은 별도 검토가 필요하다.

## 산출물과 호환성

- 3D에 주행보·상인방을 별도 부재명으로 표시한다. 크레인 지지점 마커는 실제 기둥 지지점만 표시한다.
- 부재 표·CSV·계산서·물량표에서 주행보 및 상인방을 플랫폼 보와 구분한다. 모델링한 강재는 물량에 포함하고 레일·브래킷·문 하드웨어·신설 접합 상세는 제외한다.
- 계산서는 입력·출처·제약, 실제 부재와 요소 대응 및 조합 근거를 기록한다. S8 측벽 입면에 주행보와 출입문을 표시한다.
- 기존 추가 입력이 없거나 새 선택 기능을 끈 프로젝트는 기존 모델을 유지한다. 기본 단면 최적화는 선택한 주행보·상인방 단면을 덮어쓰지 않는다.
- 기존 1~4단계와 같이 크레인 조합은 중력+크레인 범위다. 풍·지진 동시성, 복수 크레인, 지진 시스템 재선정·모달 질량, 신설 부재 가상하중 등은 전문가 검토에 남는다.

## 검증

- `node --import tsx scripts/verify-phase5.ts`: TW/CN/KR 하중·전역 모멘트 보존, 거트 제거와 실제 강재 물량·지진중량, 주행보 차륜하중 중복 방지, 물리 경간의 단부 해제와 비지지 길이, 상대 처짐 및 지지점 분류, 출처 확인과 가새 베이 차단을 검사한다.
- `node scripts/verify-all.mjs`: 기존 정답 모델을 포함한 22개 오프라인 검증 묶음.
- PDF 검증에 5단계 예시를 추가하여 총 20개 계산서를 4개 언어로 생성하고 글리프를 확인한다. 새 글자에 맞춰 PDF 축소 글꼴을 갱신했다.
- `node --import tsx scripts/live-additions.ts --phase5`: 3베이 `[5, 7, 4]`, 지붕 설비·크레인·플랫폼·주행보·닫힌 출입문을 함께 생성한다. 키는 `.env`에서 읽어 출력하지 않는다. 시험 종료 시 원본을 다시 열고 12개 DB 해시로 복원을 확인한다.
- 라이브 수치는 모델 연동·해석·결과 완전성·반력 평형 검증이다. 샘플 단면의 NG는 유지하며, Gen 자체 설계 강도비와 앱의 독립 대조를 의미하지 않는다.

### 라이브 결과

오프라인 22개 묶음과 빌드 통과. 최종 5단계 전용 검사는 **6,071개** 통과했다. 기존 TW/CN/KR 정답 모델을 유지하고 20개 PDF의 글리프 검사를 통과했다. 브라우저에서 입력 표시·단면 선택·가새 베이 선택 차단·출처 확인·미리보기 갱신을 확인했다. 검토 화면은 `output/phase5-ui.png`다.

반력 평형은 전송 선·절점 하중과 Gen 반력을 비교한다. Gen DB 자중이 포함되는 D는 이 평형 비교에서 제외했다. 샘플 NG는 설계 적합 통과를 의미하지 않는다. 실제 부재와 하중 경로가 많은 모델은 수백 개 조합의 결과 회수에 수분이 걸릴 수 있다.

시험 후 원본 복원 **12개 DB 해시 모두 일치**. 증거는 `output/additions-live-20261017095648469/evidence.json`과 같은 폴더의 TW/CN/KR 계산서다. 라이브 실행 후 변경한 항목은 실제 골조선만 크레인 지지점 사용성 대상으로 분류하는 보정, 화면 표시·입력 선택 및 문서다. 지지점 분류 보정은 전용 합성 변위 시험으로 확인했으며, 라이브 전송 형상·하중은 동일하다.

### 2026-10-18 보강 샘플 재해석

원래 샘플을 재실행한 결과 부재 NG·최대비·반력 평형이 기존 기록과 동일했다. 주요 초과는 플랫폼 보 휨, TW/KR 퍼린·거트 및 퍼린 처짐, CN 플랫폼 처짐이었다. 검증용 단면을 명시적으로 변경하고 Gen에서 다시 해석했다. 기본 설계값·사용자 입력·하중계수·기하 형상은 변경하지 않았다. 단면 변경에 따른 강성·자중·정적 지진중량 변화는 재해석에 포함했다.

| 기준 | 플랫폼 보 | 스트럿 | 퍼린 / 거트 | 가새 |
|---|---|---|---|---|
| TW | RH 800x300x14x26 | RH 300x300x10x15 | CC 250x75x25/4.5 / CC 200x75x25/4.5 | P 165.2x6 |
| CN | HN 800x300x14/26 | HW 300x300x10/15 | 기존 단면 유지 | P 273x8 |
| KR | H 800x300x14/26 | H 300x300x10/15 | LC-250x75x25x4.5 / LC-200x75x25x4.5 | P 190.7x6 |

| 기준 | 최대 부재비 | 부재 NG | 사용성 NG | 접합 NG | 최대 반력 평형 오차 |
|---|---:|---:|---:|---:|---:|
| TW | 0.9184 | 0 | 0 | 0 | 0.0004% |
| CN | 0.8084 | 0 | 0 | 0 | 0.0007% |
| KR | 0.8379 | 0 | 0 | 0 | 0.0204% |

플랫폼·2차 부재 보강 후 스트럿 압축력이 증가했고, 스트럿 보강 후 CN/KR 가새가 약 1.03까지 초과해 추가 보완했다. 이 중간 NG를 숨기지 않고 각 실행의 증거에 보존했다. 최종 TW 증거는 `output/additions-live-20261018010141980/TW-design.json`, 최종 CN/KR은 `output/additions-live-20261018011415711/`이다. 각 실행 후 원본 12개 DB 해시가 일치했다.

재현 명령: `node --import tsx scripts/live-additions.ts --phase5 --strengthened`. `--codes=CN,KR`처럼 국가를 한정할 수도 있다. `*-design.json`에 정확한 입력·모든 부재의 지배 조합/검토식/부재력/내력·사용성·접합 결과를, `evidence.json`에는 용도별 지배 부재와 요약을 저장한다. 샘플 보강은 최소중량 최적화나 앱 기본 단면 변경이 아니며, 추가 부재의 자동 단면 최적화도 구현하지 않는다. 계산 NG 0이어도 추가 구조의 전문가 검토 범위 및 Gen 자체 강도비와의 독립 대조 제외는 유지한다.
