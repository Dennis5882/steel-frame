## 범위와 판정

`.env`의 키를 사용해 실제 Gen NX에 모델을 전송하고 해석·결과 회수 후 앱의 국가별 검토를 실행했다. API 키는 산출물에 저장하지 않았다.

- **연동 통과**: 실제 단면 성질 대조, 모델·하중 전송, 해석, 전체 결과 회수와 전송 하중 대비 반력 평형 확인. 평형 상대오차 허용치는 0.2%이며 DB 자중을 따로 재구성하지 않는 D 케이스는 제외한다.
- **설계 결과**: 앱이 제공하는 부재·사용성·기존 접합 검토의 결과다. 기본 단면 또는 시험용 단면이 NG일 수 있다. 연동 통과와 구분한다.
- 냉간성형·추가 구조의 예비검토, 횡지지 가정 및 접합·기초 상세의 기존 한계를 유지한다. Gen 자체 국가별 강재 설계 결과와의 독립 대조를 이번 시험의 통과 조건으로 사용하지 않았다.
- 시험 그룹마다 열린 문서를 먼저 저장하고 종료 후 복원한다. UNIT/MATL/SECT/NODE/ELEM/CONS/FRLS/STLD/LCOM-GEN/BODF/BMLD/CNLD의 12개 DB 해시로 확인한다.

## 확인된 보완 우선순위

1. **형상별 초기 단면**: 현재 기본 단면을 편경사·다경간에 그대로 적용하면 TW 풍주, CN 지붕보, KR 지붕보·퍼린이 부족할 수 있다. 형상별 시작 단면 또는 생성 전 보완 안내를 개선할 필요가 있다.
2. **플랫폼 초기 단면과 사용성**: 기본 플랫폼 보를 실제 하중·경간에 대한 적합 단면으로 보장하지 않는다. 플랫폼 입력 단계에서 강도·처짐 예비 결과와 단면 보완 경로를 더 잘 보여주는 것이 유용하다.
3. **보완 후 재해석 유지**: 실제 보완값은 기존 부재력의 예상값과 달랐다. 현재 예상/확인 결과 분리와 재해석 절차를 유지해야 한다.

이번 검증에서 확인한 기능 범위와 기존 검토 한계를 위 표와 본문에 한정한다. 국가별 규범 전체, 미지원 접합 상세, Gen 자체 강재 설계와의 독립 대조 및 자동 중량 최적화의 반복 수렴을 모두 새로 검증한 것은 아니다.
