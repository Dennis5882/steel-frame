- 날짜·시험 수치·실패·미지원·예비검토 한계를 과거 기록으로 보존한다.

- 원시 증거의 `output/...` 경로는 저장소 루트 기준이다. Git 제외 자료이므로 별도 보존 여부를 확인한다.
