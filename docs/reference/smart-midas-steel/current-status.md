# 현재 구현 현황

기준 버전: **v2.4.1** · 마지막 검토: 2026-10-19

이번 정리는 코드와 기존 검증 기록을 대조한 문서 검토다. 새로운 Gen 해석이나 규범 검증을 실행한 기록이 아니다. 과거 v0.x/v1.x 평가의 점수를 현재 완성도 점수로 이어 쓰지 않는다.

## 1. 현재 제품의 범위

대만·중국·한국 기준을 구분하는 단층 공장용 웹 도구다. 클릭형 입력에서 Gen 모델·하중 생성, 해석, 결과 회수, 웹 부재·사용성·접합 검토, 단면 최적화/수동 보완, HTML/PDF·DXF·CSV까지 연결된다.

**구현 완료**, **시험 사례의 연동 통과**, **수치 NG 없음**, **예비검토**, **전문가 확인 완료**는 각각 다른 상태다. Gen의 모델·해석 및 DB 성질을 사용하지만 국가별 설계 검토 전체가 Gen 자체 설계 엔진의 결과인 것은 아니다.

| 형상·입력 | 박공·편경사·다경간, 등간격/개별 베이, 핀/고정, 기본/자유골조 공통 검증 | [planFields](../src/components/planFields.ts), `verify-input`·`verify-frames` |

## 3. 추가 구조의 현재 지원 수준

| 기능 | 구현된 범위 | 남아 있는 경계 |
|---|---|---|
| 천장 크레인 | 단일 크레인·레일당 2차륜, 골조 영향/주행보 선택, 전체/일부 베이, 충격·횡력·제동력 입력, 정적 위치 샘플·편심·상대 처짐·지진중량 | 크레인+풍/지진 동시 조합 확대, 피로·레일·차륜 국부지압·브래킷/접합 상세·복수 크레인 등은 미완료 |
| 메자닌·플랫폼 | 부분 평면 범위, 보·기둥 격자, 하중·지진중량·단면 예비검토 | 슬래브/합성·다이어프램·난간/계단·상세 접합 및 시스템 적합성 별도 |
| 지붕 설비 | 위치·집중중량·지진반영분·하중 출처 | 기계 진동·기초·비정형 장비 지지 상세 별도 |
| 측벽 개구부 | 가새 없는 한 베이의 닫힌 출입문, 거트 제거 및 하중 전달·상인방 | 열린 문에 따른 내압 변화·가새 재배치·임의 형상 개구부 미지원 |
| 지붕·바닥 개구부 | 닫힌 지붕 덮개의 보강/하중 전달, 플랫폼 격자에 맞는 바닥 빈 면적·하중/중량 제외 | 열린 지붕·임의 위치/형상·덮개 국부 검토·상세 접합 별도. 지붕 보강 처짐은 웹 추정 |
| 다경간 | 경간 목록·내부 기둥·경간별 처짐, 국가별 제한·가정 표시 | 내부 접합·골 거터·일부 풍/적설 해석 가정의 독립 검증 필요 |
| 건물 연결부 | 분리/미끄럼의 이동·이격·받침 검토, 확인된 외부 6성분 반력 인터페이스 | 연결 건물 전체 생성·일체형 결합·비선형 링크/충돌 해석 미지원 |

기본 입력·출처 확인 전 생성 차단 및 확인 후 예비검토 등급은 유지한다. 원안의 “설비층·연결동·큰 개구부 전체”가 모두 구현됐다고 분류하지 않는다.

상세 근거: [1~4단계](reference/factory-additions-phases-1-4.md), [5단계](reference/factory-additions-phase-5.md), [6단계](reference/factory-additions-phase-6.md), [크레인 구간](reference/crane-travel-range.md).

## 4. 국가별 차이와 보완 방향

세 국가의 업무 흐름과 기본 검증 기반은 공통화됐다. 계산의 독립 검증 수준과 규범별 상세 범위까지 동일하다고 보지는 않는다.

| 기준 | 현재 근거 | 다음 보완 초점 |
|---|---|---|
| TW | LRFD·지역/지반 계수, 원문 기반 압축 Q·냉간 뒤틀림·양 연단 검토, 실제 기본 모델 fixture | 냉간 약축 유효폭·편심 비틀림·웨브 지압/접합 상세, 제공 원문의 판본·정오표 확인 |
| CN | 별도 GB/门式刚架 하중·부재·접합 경로, 실제 기본 모델 fixture | GB 50017-2017과 동일 조건의 독립 대조, C형강 근사·변단면/좌굴후 미지원 범위. Gen 구판 설계 결과를 현 판본의 정답으로 사용하지 않음 |
| KR | KDS 하중·부재·외장재·접합·냉간·선택적 내진 상세, 일부 Gen 요소별 대조 | 잔여 기둥 차이의 B1/B2·두께/재료 조건 추적, Cb/길이·하중 포락 일치, 냉간·앵커 정착·접합 회전성능 |

규범 조항은 제공된 원문/KB에 기반한 구현 설명이다. 이번 문서 정리에서 규범 최신성이나 전체 적합성을 새로 인증하지 않았다.

## 5. 검증 현황

- 직전 커밋 작업에서 `npm run build` 및 공통 오프라인 **27종** 통과. 국가별 정답·하중·입력·동기화·보완·PDF/글꼴 등이 포함된다. [검증 목록](../scripts/verify-all.mjs).
- v2.3.2: 기본 골조 9건 + 추가 구조/단면 보완 등 총 **21회** 라이브. 기본 단면 NG와 최종 보완 결과를 구분한다. [기록](archive/2026-10-19/live-validation-v2.3.2.md).
- v2.3.4 크레인 구간: TW/CN/KR × 전체/일부 = **6건**, 정적 사례 726개·조합 2,068개. 최대 반력 평형 상대오차 0.001341% 미만, 각 시험 그룹의 원본 12 DB 해시 일치. [기록](reference/crane-travel-range.md).
- 크레인 라이브 행렬의 횡력·제동력은 0이었다. 비영 하중·양방향·불균등 범위는 오프라인 5,640사례로 확인했다. 이를 동일한 라이브 검증으로 표기하지 않는다.
- 마지막 KR 일부 구간은 Node 네트워크 런타임 장애 후 수동 복구·별도 재시험으로 완료했다. 자동 복구가 모든 프로세스 장애에서 검증됐다는 뜻은 아니다.
- 국가별 기본 골조 fixture는 존재한다. “CN/KR 전체 결과 fixture가 없다”는 과거 평가는 현재 과제가 아니다. 형상·경계값·특수 하중 조합의 확대는 계속 필요하다.

## 6. 아직 완료되지 않은 주요 항목

1. 프로젝트 파일 저장·불러오기와 입력/결과 개정 관리. 현재 테마·선호 코드 저장과 Gen 백업은 프로젝트 저장 기능을 대신하지 않는다.
2. 국가·형상·크기별 템플릿과 기본 단면의 적합 범위 안내. 36×80m 크레인 시험은 기본 단면에서 많은 NG가 나왔으며 CN 증폭계수 B=99 사례도 기록돼 있다.
3. 라이브 시험 프로세스 강제 종료·통신 장애의 자동 복구와 장시간 결과 회수 계측.
4. 동일 조건의 국가별 계산 대조, 냉간/접합/크레인의 남은 상세 검토.
5. 프로젝트 개정과 연결된 산출물·검증 증거의 보존 및 실제 사용자 작업 시험.

세부 작업·완료 기준은 [개선 로드맵](roadmap.md)에서만 관리한다. 이번 문서 정리에서 기능을 추가하거나 과거 NG를 해결한 것으로 처리하지 않았다.
