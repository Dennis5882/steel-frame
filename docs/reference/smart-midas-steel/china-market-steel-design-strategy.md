# 중국 시장 강구조 공장 설계: 조사와 제품 개선 방향

작성일: 2026-10-19 · 상태: 조사·제안, 구현 승인 및 완료 기록 아님

## 1. 목적과 결론

YJK-PMGJ, PKPM-STS, 3D3S의 공식 자료를 참고해 중국 공장 설계 업무에 맞는 제품 대상과 개선 방향을 정리한다.

우선 대상은 **MIDAS Gen NX를 사용하는 구조 엔지니어가 정형·등단면 공장의 모델링, 조건 변경, 해석 및 설계 검토를 빠르게 수행하는 업무**로 제안한다.

중국판의 핵심 개선 방향은 다음과 같다.

1. 프로젝트 자료의 내진·지반 조건을 계산 입력값과 연결한다.
2. 축망, 표준 골조, 크레인 위치와 하중 전달을 하나의 모델에서 이해하게 한다.
3. 자동 처리 범위와 별도 설계가 필요한 범위를 구분한다.
4. 입력 근거부터 계산 결과까지 추적 가능한 중국어 계산서를 제공한다.
5. 용접 변단면 골조는 시장 확대를 위한 별도 개발 과제로 평가한다.

공통 기능의 전체 우선순위는 [개선 로드맵](roadmap.md)에서 관리한다. 이 문서의 중국판 제안 순서는 기존 프로젝트 저장·복원, 계산 검증 등 공통 과제의 우선순위를 대체하지 않는다.

## 2. 조사 범위와 해석상의 한계

- 근거는 공급사의 공식 제품 소개, 사용자 자료 및 설계 사례다. 출처는 문서 마지막에 정리한다.
- 경쟁 프로그램을 직접 설치해 동일 모델로 비교한 시험은 수행하지 않았다.
- 제품 소개의 기능 제공 여부와 실제 프로젝트의 계산 정확성, 사용성, 라이선스 범위는 구분한다.
- YJK-PMGJ와 YJK 전체 제품군, 3D3S Design과 Solid의 기능을 혼합하지 않는다.
- 과거 사례와 신규 버전 발표를 구분한다. 발표된 기능이 현재 설치본에 제공되는지는 별도 확인이 필요하다.
- 시장 점유율, 변단면 사용 비율, 고객의 지불 의사는 이번 자료만으로 판단하지 않는다.
- 아래의 화면 구성과 개발 순서는 조사에 근거한 제품 제안이다. 구조 계산 규칙의 확정이나 현행 규범 적합성 인증을 의미하지 않는다.

## 3. 경쟁 제품에서 확인한 업무 흐름

| 제품·모듈 | 공식 자료에서 확인한 특징 | 참고할 제품 방향 |
|---|---|---|
| YJK-PMGJ | 문형 골조의 2차원 모델 입력, 자동 하중 전달, 단면 최적화, 구조 계산, 접합부 설계, 시공도 작성 | 횡단면 중심의 간결한 입력과 계산 근거 확인 |
| PKPM-STS 공장 설계 | 프로젝트 총정보, 횡·종방향 표준 골조, 크레인, 가새, 지붕 2차 부재를 연결한 설계 사례 | 축망·표준 골조 관리와 하중 전달 |
| 3D3S Design 공장 모듈 | 골조별 매개변수 모델링과 연동 수정, 가새 생성, 하중 구역 설정, 계산 결과의 3D 표시 | 모델 위치 선택과 시각적인 결과 확인 |

근거: [S1], [S2], [S4].

### 3.1 표준 골조와 전체 모델의 관계

PKPM의 2023년 공식 사례는 단부 골조를 GJ-1, 나머지를 GJ-2로 구분한다. 형상과 하중 조건에 따라 표준 골조를 구성하고, 종방향 가새 골조도 별도로 관리한다. YJK의 V6 소개 역시 골조 관리와 2D·3D 데이터 연계를 강조한다. [S2], [S5]

따라서 대표 골조를 반복하는 방식에서 다음 단계로 발전시키려면 **표준 골조 + 적용 축선 + 위치별 예외**가 필요하다.

### 3.2 3D 표현과 해석 방식의 구분

3D 미리보기, 3D 배치 후 평면 골조별 계산, 전체 공간 모델 해석은 서로 다르다.

PKPM은 2024년 발표에서 2025R2.0에 국부 중층 모델링과 SATWE 전체 3차원 해석을 제공할 계획을 설명했다. 따라서 STS 전체를 일괄적으로 2D 전용이라고 설명하지 않는다. 실제 비교 시 버전·모듈·해석 방식을 기록한다. [S3]

## 4. 우선 고객과 적용 범위

### 4.1 우선 고객 가설

- Gen NX를 이미 사용하는 구조 엔지니어와 설계팀.
- 정형 공장 모델을 반복 생성하거나 치수·단면·크레인 조건을 비교하는 사용자.
- 생성된 모델과 하중, 계산 근거를 직접 확인하고 후속 설계를 수행할 사용자.

제품 가치는 **반복 입력 감소, 조건 변경의 일관성, Gen 모델과 웹 검토 결과의 연결**로 제안한다. 실제 효용은 중국 현지 사용자 작업 시험으로 확인해야 한다.

### 4.2 범위를 명확히 해야 하는 프로젝트

용접 변단면, 복수 크레인, 복잡한 고저차, 비정형 배치, 기둥 생략과 전달 구조, 상세 제작도 중심 업무는 별도의 요구사항과 검증 범위가 필요하다. 현재 기능으로 모델 일부를 생성할 수 있어도 해당 프로젝트의 전체 설계를 완료했다고 표시하지 않는다.

중국어 안내 문안 초안:

> 面向规则、等截面钢结构厂房的参数化建模与设计校核，联动 MIDAS Gen NX 完成结构分析。

화면에서는 각 기능을 **自动处理 / 需补充输入 / 需专项设计**로 구분하고, 최종 결과에서도 미검토 항목을 유지한다.

현재 지원 여부의 기준은 [현재 구현 현황](current-status.md)과 [중국 기준 구현](reference/china_code_implementation.md)이다. 이 문서의 타깃 문안이 개별 기능의 지원을 새로 보장하지 않는다.

## 5. 중국 프로젝트·내진 조건 입력 보조

### 5.1 현재 문제

현재 `china.alphaMax`, `Tg`, `Tx`, `Ty` 중심 입력은 값을 이미 아는 전문가에게 직접적이다. 프로젝트 설계 조건과 지반조사 자료를 보고 시작하는 사용자에게는 각 값의 출처와 관계가 충분히 드러나지 않는다.

### 5.2 권장 흐름

**프로젝트 조건 입력 → 적용값·근거 확인 → 전문가 수정 → 해석 전 확인**

기존 지역·하중 단계 안에 보조 입력을 구성한다. 새 마법사 단계 추가는 우선 요구하지 않는다.

| 입력 묶음 | 중국어 표시 예시 | 주된 근거 |
|---|---|---|
| 프로젝트 위치 | 项目所在地 | 프로젝트 기본 자료와 위치 |
| 내진 요구조건 | 抗震设防烈度、设计基本地震加速度、设计地震分组 | 프로젝트 설계 조건과 적용 지역 자료 |
| 지반 조건 | 场地类别 | 지반조사 보고서 |
| 건축물 조건 | 抗震设防类别 | 프로젝트 설계 요구사항 |
| 계산 적용값 | αmax、Tg、阻尼比 | 적용 규범과 확인된 조건 |
| 구조 고유주기 | 横向周期 Tx、纵向周期 Ty | 프로젝트 제공값, 예비 추정 또는 해석 결과 |

위 표는 입력 설계안이다. 조건 간 매핑과 예외는 적용 규범 판본 및 원문 대조 후 구현한다. 프로젝트 위치만으로 모든 지반·내진 조건을 확정하지 않는다.

### 5.3 계수와 고유주기의 구분

- αmax·Tg는 관련 내진·지반 조건과 적용 기준을 연결해 근거를 보여준다.
- Tx·Ty는 구조물의 고유주기다. 지역 선택으로 자동 확정하지 않는다.
- 주기는 프로젝트 제공값, 예비 추정값, Gen NX 해석 결과를 구분해 기록한다.
- 모델 강성·질량 변경 시 기존 주기의 최신성을 확인한다. 모드해석 연계는 별도 구현·검증 대상이다.
- 직접 수정한 값에는 수정 사유와 출처를 남긴다.
- 자료가 없으면 미확인으로 보존한다. 모델링 진행 여부와 해석·검토 진행 조건은 구분한다.

### 5.4 완료 기준 제안

- 사용자가 자료의 어느 항목을 옮겨야 하는지 알 수 있다.
- 적용값마다 입력 조건, 규범 판본, 출처와 수동 수정 여부를 확인할 수 있다.
- 자료 부족을 정상적인 확정값으로 숨기지 않는다.
- 전문가 직접 입력 경로를 유지한다.
- 확인된 기준 사례와 경계·예외 조건을 독립 계산으로 대조한다.

## 6. 축망·표준 골조 모델링

### 6.1 권장 조작

1. 기본 골조를 만들고 적용 축선에 배치한다.
2. 단부 골조와 내부 골조를 구분한다.
3. 선택 축선의 단면·하중·구조 조건만 수정할 수 있게 한다.
4. 표준 골조 수정 시 함께 변경될 위치를 먼저 표시한다.
5. 위치별 예외와 표준 골조의 차이를 확인할 수 있게 한다.

3D3S 공식 자료의 골조별 연동 수정과 PKPM 사례의 표준 골조 구분을 참고한 제안이다. [S2], [S4]

### 6.2 중국어 용어

| 대상 | 권장 표현 |
|---|---|
| 횡방향 경간 | 跨度 |
| 종방향 기둥 간격 | 柱距 |
| 골조 한 벌 | 一榀刚架 |
| 기준선·축망 | 轴线／轴网 |

‘베이’를 모든 위치에서 동일하게 번역하지 않는다. 화면과 계산서에서 방향·축선 표기를 일치시킨다.

## 7. 크레인 업무 개선

현재 전체·일부 구간 선택과 크레인 하중 입력을 기반으로, 자료 입력과 하중 전달을 더 명확하게 만든다. 기존 기능을 신규 기능으로 중복 등록하지 않는다.

### 7.1 입력 순서 제안

**제조사·장비 자료 → 운행 구간 → 레일·브래킷 위치 → 차륜 배치 → 최대·최소 윤압 → 충격·수평력 → 근거 확인**

- 제조사·기종·자료 개정 정보와 하중 근거를 연결한다.
- 레일 높이, 브래킷 높이, 장비 여유 공간의 의미를 도해로 구분한다.
- 정격 인양하중만으로 윤압을 확정하지 않는다.
- 전체 운행 구간을 기본으로 두되, 일부 구간을 모델에서 선택할 수 있게 한다.
- 현재 지원 차륜 배치와 크레인 수의 제한을 입력 초기에 안내한다.

### 7.2 하중 전달과 검토 범위

모델에서 **크레인 → 주행보 → 브래킷·기둥 → 종방향 가새**의 전달 경로를 확인하게 한다. PKPM 공식 사례의 횡·종방향 하중 전달과 3D3S의 공간 크레인 기능을 참고한다. [S2], [S4]

다음 항목은 각각 완료·미검토·별도 설계 상태를 표시한다.

- 주골조의 크레인 하중 영향.
- 주행보 강도·안정·처짐.
- 풍·지진과 크레인 작용의 적용 조합.
- 복수 크레인과 동시 운행.
- 피로, 차륜 국부 작용, 레일·브래킷·접합 상세.

입력 UX 개선과 구조 계산 범위 확대는 별도 작업으로 검증한다. 기존 라이브 시험의 통과가 위 모든 항목의 검증을 의미하지 않는다.

## 8. 하중 확인과 중국어 산출물

PKPM 공식 설명은 풍하중 자동 배치, 적설 분포, 상호 배타 하중, 특수 하중과 조합 확인을 다룬다. 이를 참고해 숫자 입력 후 실제 모델에 무엇이 적용됐는지 확인하는 흐름을 강화한다. [S6]

### 8.1 하중 화면 제안

- 풍압 구역과 부재에 전달된 방향·크기를 표시한다.
- 적설 및 지붕 활하중의 적용 배치와 조합 관계를 보여준다.
- 생성된 하중 케이스·조합, 사용자 변경, 제외한 작용을 구분한다.
- 집진·유지관리 등 특수 하중은 프로젝트별 필요성을 먼저 확인한다.
- 특수 형상이나 미지원 하중은 지원되는 일반 조건으로 조용히 치환하지 않는다.

### 8.2 산출물 제안

- 프로젝트·모델 개정과 적용 규범 판본.
- 내진·풍·적설 입력 조건 및 자료 출처.
- 해석 방식, 질량·지지·유효길이 가정.
- 축선·골조·부재별 지배 조합, 계산값·허용값·검토비.
- 크레인 배치와 검토 범위, 남은 상세 설계 항목.
- 주구조·2차 부재 등 포함 범위를 밝힌 강재 물량표.
- Gen 해석 결과와 웹의 규범 검토 결과의 출처 구분.

현재 제공되는 출력 형식을 재구현하는 과제가 아니다. 기존 HTML/PDF·Word·DXF·CSV에 필요한 정보와 일관성을 보강하는 제안이다. 개략 DXF와 상세 시공도·제작도는 구분한다.

## 9. 용접 변단면 골조의 별도 평가

YJK 공식 자료에는 용접 조립 H형강과 변단면 관련 최적화 조건이 포함된다. 중국 시장의 적용 대상 확대를 위해 검토할 가치가 있으나, 이 자료만으로 수요 규모나 사용 비율을 단정하지 않는다. [S7]

변단면 지원은 단면 선택 목록 추가로 완료되지 않는다. 다음 범위를 함께 평가한다.

- 부재 양단·중간 단면과 테이퍼 형상 정의.
- Gen 모델 생성·회수와 실제 단면 성질의 일치.
- 해당 부재의 강도·국부 및 전체 안정 검토.
- 유효길이·횡지지·접합부 가정.
- 단면 최적화, 물량, 도면과 계산서의 일관성.
- 동일 조건의 독립 예제 및 라이브 해석 검증.

별도 타당성 검토 결과로 범위·비용·검증 계획을 확정한다. 현재의 등단면 검증 결과를 변단면 검증으로 재사용하지 않는다.

## 10. 중국판 개선 순서와 완료 기준

| 순서 | 제안 ID | 작업 | 완료 기준 |
|---:|---|---|---|
| 1 | CN-M01 | 프로젝트·내진 조건 보조 입력 | 자료 항목에서 적용값까지 추적되고, 계수와 고유주기의 출처가 구분됨 |
| 2 | CN-M02 | 크레인 입력·전달·검토 범위 | 위치와 하중 경로를 확인하고, 미지원 항목을 완료로 오해하지 않음 |
| 3 | CN-M03 | 축망·표준 골조·예외 수정 | 단부·내부 골조를 배치하고 특정 축선 수정과 연동 범위를 확인함 |
| 4 | CN-M04 | 하중·조합·계산서 추적성 | 입력 근거, 실제 하중, 지배 조합과 결과가 같은 개정으로 연결됨 |
| 별도 | CN-M05 | 용접 변단면 타당성 검토 | 대상 부재·규범·Gen 연계·독립 검증 범위와 개발 계획이 정해짐 |

이 ID는 제안 추적용이다. 구현 착수 시 기존 로드맵 R04·R05·R06·R08·R09 등과 중복을 조정하고 승인된 작업 범위로 편입한다.

### 현지 사용자 작업 시험 제안

중국 실무자에게 익명화된 프로젝트 조건·지반 자료·크레인 자료를 제공하고 다음을 관찰한다.

1. 모델 생성 및 해석·검토까지 걸리는 시간과 도움 요청 횟수.
2. 내진 조건·높이·방향·단위의 오입력과 수정 과정.
3. 하중 전달과 미검토 항목을 정확히 설명할 수 있는지.
4. 생성된 Gen 모델과 계산서를 검토·인계할 수 있는지.
5. 실제 프로젝트에서 등단면 범위가 충분한지, 변단면 부재가 필요한지.

경쟁 제품과 속도를 비교하려면 동일 프로젝트·산출 범위·사용자 숙련도를 맞춘다. 시험 전부터 생산성 향상률이나 시장 적합성을 확정하지 않는다.
