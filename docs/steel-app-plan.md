# 스틸 프레임 Agent — 분리 앱 계획서 (개정 초안)

작성일 2026-10-19 · **개정 2026-10-19: CN 우선, Smart MIDAS Steel(문형 공장 앱) 기반으로 방향 변경**
상태: 초안. 단계 0(게이트) 확인 전에는 구현에 들어가지 않는다.

> **개정 요지**
> - 1차 기준을 TW에서 **CN(GB)** 으로 바꾼다. 대상 사례는 Gen NX 예제 `钢支撑框架分析设计操作例题-GEN NX.docx`(4층 강 가새골조)이다.
> - 출발점을 "RC구조물 Agent 복제"에서 **Smart MIDAS Steel(`E:/AI Study/smart-midas-steel`, v2.4.3) 참고·재사용**으로 바꾼다.
>   이유: 강재·단면 Gen API, CN 하중·강재 검토, 계산서·도면, 라이브 검증 체계가 이미 그 앱에서 구현·확인돼 있다.
>   RC 앱을 복제하면 RC 코드를 걷어내고 스틸 부분을 처음부터 다시 만들게 된다.
> - 1차 범위에 **응답스펙트럼(RS) 해석과 층 검토 지표**를 넣는다. 예제의 핵심이고 공장 앱에는 아직 없는 기능이다.

## 1. 목적과 범위

| 항목 | 내용 |
| --- | --- |
| 제품 | MIDAS Gen NX Open API로 **다층 강구조 골조(모멘트골조·가새골조)를 자동 모델링·해석**하고, 층 검토 지표와 부재 검토를 보여주는 웹 도구 |
| 이름(가칭) | 스틸구조물 Agent (Smart MIDAS Steel의 자매 앱) |
| 기준 예제 | 4층 강 가새골조. 평면 6000×4 = 24 m × 4000×4 = 16 m, 층고 4.5 m + 3.3 m×3 = 14.4 m. 보 HW200×200×8/12, 기둥 HW250×250×9/14, 가새 HW150×150×7/10. 재료 Q355, 기둥 하부 고정. 하중: 바닥 DL 5·LL 2 kN/m², 지붕 DL 2·LL 0.5 kN/m², 보 선하중(바닥 5, 지붕 1 kN/m), 풍하중, 반응스펙트럼 RX·RY |
| 범위(1차) | 격자 다층 골조 생성(모멘트골조 + 가새골조), 바닥하중 분배, 자중·하중의 질량 변환, 고유치 해석, 응답스펙트럼(GB 50011), 하중조합, 층 결과 표, **층 검토 지표**, 부재 검토(GB 50017-2017, 앱 자체 계산), 계산서(PDF/Word) |

| 설계기준 | **1차 = CN 하나**: GB 55001-2021(하중 조합), GB 50009-2012(풍), GB 50011-2010(2024 개정, 지진·반응스펙트럼·비정형), GB 50017-2017(강재 검토). 이후 KR → TW 순으로 확장 |
| 비목표 | RC 앱 기능 변경, Smart MIDAS Steel 화면에 다층 모드 추가(두 앱 통합) |

**원칙**: RC 앱과 공장 앱의 동작은 바꾸지 않는다. 공장 앱의 검증된 순수 모듈(`codes/`, `domain/` 일부)은 그대로 가져오고, 다층 전용 형상·하중·층 검토만 새로 작성한다. 기준 의존 로직은 `CodeProfile`로 격리한다.

## 2. 먼저 확인할 것 (착수 전 게이트)

### 2.1 공장 앱에서 이미 확인된 것 — 다시 조사하지 않는다

| 항목 | 확인 내용 (Smart MIDAS Steel, 라이브 2026-10-14~19) |
| --- | --- |
| MAPI 연결 | 브라우저 직접 호출(`midas-nx` SDK). 키는 메모리에만 보관. 간체 zh-CN은 `moa-engineers.midasit.cn`, 그 외는 `.com` |
| 저장 창 방지 | `doc/new`·`doc/anal` 직전에 반드시 `doc/saveas`. 저장되지 않은 문서로 해석하면 Gen 대화상자가 남아 **API 전체가 멈춘다** |
| 강재 재료 | `db/MATL` TYPE STEEL. CN은 규격 `GB03(S)`, DB Q235·Q345(Q235B 같은 등급 접미사는 거부되므로 프로필에서 매핑) |
| 단면 DB | CN `GB-YB05`(HN·HW·HM, `SHAPE` H), 냉간 `GB50018-02`. 강관 P. 단면 성질은 Gen DB 값(A·I·J·소성계수)을 기준값으로 사용하고 전송 후 대조 |
| 가새 | TRUSS 요소. `USE_WARPING_EFFECT:false` 필수(없으면 "7th DOF" 오류) |
| Gen 규칙 | TRUSS에는 보 하중 불가(절점하중으로 대체). 한 절점에 같은 케이스 CNLD가 둘이면 하나만 남음(합산 전송). 조합 이름 ≤ 20자 |
| 전송 확인 | 보낸 DB(MATL·SECT·NODE·ELEM·FRLS·CONS·STLD·LCOM·BODF·BMLD·CNLD) 개수·필드를 GET으로 대조. 해석 전에 Gen 모델 변경 감지(13개 DB) |
| 결과 회수 | `post/TABLE` BEAMFORCE·TRUSSFORCE·REACTIONG. 큰 표는 분할 회수. 브라우저에서 `push(...arr)` 금지(스택 초과) |
| 화면 제어 | `/view/ANGLE` + `/view/CAPTURE {ZOOM_LEVEL:100}`로 ISO 전체 보기, 해석 후 `/view/RESULTGRAPHIC`로 후처리 모드·반력 표시 |
| CN 설계 API | 공개 Gen 강재 설계 API가 구판이라 **공장 앱은 CN에서 DSTL을 보내지 않고 앱 자체 계산**으로 검토 |

### 2.2 새로 확인해야 하는 것 (다층·RS 전용)

예제의 GUI 절차를 API로 재현할 수 있는지 단독 사용 시간에 라이브로 확인한다. 시험 PUT은 확인 후 DELETE로 원복하고, 원본 문서는 저장 후 12개 DB 해시로 복원을 확인한다.

1. **재료 Q355**: 예제는 규격 `GB 50017-17(s)`, DB Q355를 쓴다. 공장 앱은 `GB03(S)` Q235·Q345만 확인했다 → 새 규격 이름과 Q355 수용 여부.
2. **층 데이터**: `db/STOR`(층 정의 생성)와 강성 바닥 여부 입력. 예제의 "楼层复制·生成层数据" 대응.
3. **바닥하중**: `db/FBLA`(바닥하중 유형) + `db/FBLD`(분배)가 강재 보에서 동작하는지, 또는 앱에서 보 선하중(BMLD)으로 직접 분배할지.
4. **질량 변환**: 구조 유형(`db/STYP`, 집중질량·자중→질량 X·Y)과 하중→질량(`db/LTOM`, DL 1.0 + LL 0.5).
5. **고유치·반응스펙트럼**: 고유치 설정(`db/EIGV`, Lanczos 12모드), 스펙트럼 함수(`db/SPFC`, GB 50011 설계 스펙트럼), RS 케이스(`db/SPLC`, RX·RY 90°, 감쇠 0.02, 우발편심, CQC, 주모드 부호).
6. **층 결과 표**: `post/TABLE`로 층간변위, 층 변위, 전단중량비, 인접층 질량비, 전도모멘트, 비틀림 비정형, 횡강성 비정형, 층 수평내력 급변을 회수할 수 있는지(표 이름 확인). 안 되면 앱에서 계산.
7. **조합 자동 생성**: 예제는 GUI "自动生成"(일반·강재 설계)을 쓴다. 공장 앱처럼 **조합을 앱에서 만들어 `LCOM-GEN`으로 보내는 방식**을 기본으로 하고, RS 케이스(RX·RY)가 조합에 들어가는지 확인.
8. **GB 50017-17 강재 설계 API**: Gen NX GUI에는 GB50017-17 설계(계산길이계수 자동, 등효모멘트계수, 내진등급 2급, 한계세장비)가 있다. 최신 API에서 이 코드로 CODE-ANAL을 실행할 수 있는지 다시 확인한다.
   - 가능하면 KR처럼 **앱 자체 계산 + Gen 대조**로 쓴다(공장 앱 `live-kr.ts --gen-check` 방식).
   - 불가능하면 앱 자체 계산만 쓴다.
9. **Gen NX 공유 사용**: 다른 작업(`gen_rc_temp_*`)이 Gen을 쓰는 중이면 라이브를 멈춘다.

### 3.3 새로 작성해야 하는 핵심

- **스펙 모델**: 격자(X·Y 스팬 목록), 층고 목록, 역할별 단면(보·기둥·가새), 가새 배치(베이·층·형식 X/V/역V), 바닥·지붕 하중, 지역(지진 设防烈度·지반 유형·설계지진 그룹, 기본풍압·지면 거칠기).
- **형상 생성**: 격자 절점·기둥·보·가새 요소, 층 데이터, 지점(고정). 예제의 보 Beta 90° 규약 확인.
- **하중**: 자중(BODF), 바닥하중(FBLD 또는 앱 분배 BMLD), 보 선하중, GB 50009 풍(층별 수평력), 질량 변환, RS 케이스.
- **층 검토 지표**(GB 50011): 층간변위각(강구조 탄성 한계 1/250), 비틀림 비정형(1.2·1.5), 횡강성 비정형(연층), 층 수평내력 급변, 최소 전단중량비(λ), 인접층 질량비, P-Δ(안정계수).
- **부재 검토**: GB 50017-2017 압축·휨·압축+휨 안정, 가새 세장비 한계, 내진등급별 판폭두께비. 계산길이계수는 무측이동/측이동(가새 유무)에 따라 산정.
- **계산서**: 모델 정보 → 하중 → 고유치(주기·유효질량) → RS 결과 → 층 지표 표 → 부재 검토 → 상태 등급.

## 7. 결정이 필요한 사항 (사용자 확인 요청)

1. 다층 강골조가 필요한 구체적 사례(고객·프로젝트)가 있는가? 예제 외 실제 모델 규모는?
2. 1차 기준 CN 확정 — GB 50011 2024 개정판 기준으로 해도 되는가?
3. 1차 범위: 해석(RS 포함) + 층 지표 + 부재 검토로 고정해도 되는가? 접합부·최적화는 2차.
4. 저장소·배포: 공장 앱 복제(새 저장소·별도 Vercel 프로젝트)인가, 공장 앱 저장소 안 두 번째 진입점인가?
5. 앱 이름과 도메인(예: `frame.midasapi.space`).

## 8. 일정 (참고)

일정은 단계 0 결과에 크게 좌우되므로 확정하지 않는다. 단계 0 확인 후 단계 1~3의 소요를 다시 추정한다. 공장 앱 재사용으로 단계 1(셸)과 부재 검토·계산서 부분은 RC 복제안보다 짧아질 것으로 본다.
