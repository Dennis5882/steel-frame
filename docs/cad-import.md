# 평면도 DXF → 축망 가져오기

작성 2026-10-21 · v1.3.9 화면 포함 · 엔진 `src/frame/cad/*` · 화면 `src/components/frame/CadImport.tsx`(轴网 단계) · 문구 `src/i18n/dict/cadImport.ts` · 회귀 `scripts/verify-cad-grid.ts`

## 1. 범위

- 받는 것: **DXF만**. DWG는 지원하지 않는다. 브라우저에서 DWG를 읽을 수 있는 공개 라이브러리는 GPL(LibreDWG)이거나 유료(ODA)다.
- 읽는 것: **직교 축망의 주축**(평면 전체를 지나는 축선). 가져오면 스펙의 `xs`·`ys`(m, 첫 주축 = 0)가 된다.
  - 부분 축선(附加轴线, 평면 일부만 지남)은 따로 표시한다. 사용자가 고른 것만 격자에 넣는다.
  - 회전된 직교 축망은 회전을 풀어서 읽는다.
  - 사선·원호 축망은 읽지 않는다(`diagonal_skipped`).
- 가져오면 평면 형상(뺀 패널·삼각)과 가새는 비운다. 축 번호가 바뀌기 때문이다.
- 층고·하중·단면은 도면에 없으므로 지금처럼 직접 입력한다.
- 도면은 브라우저 안에서만 읽고 서버로 보내지 않는다.

## 2. 처리 순서 (`axisGrid.ts extractAxisGrid`)

1. **인코딩**(`decodeDxf.ts`, StruXureAI): UTF-8인지 깨진 바이트 비율로 판별한다. 아니면 `$DWGCODEPAGE`(기본 GBK)로 푼다. 2004 이하 DXF는 중국어가 GBK다.
2. **파싱**(`dxfRead.ts`): [`dxf`](https://github.com/skymakerolof/dxf) 5.3.1(MIT)로 읽고, 블록은 펼쳐서 변환을 적용한다.
   - 쓰는 객체: LINE, 폴리라인의 각 변, TEXT, MTEXT, ATTRIB, CIRCLE.
   - ATTDEF는 기본값만 들고 있어 버린다.
3. **축 레이어**: 이름에 `AXIS|AXN|GRID|DOTE|CEN|轴|軸|通|网|축|통`이 있는 레이어를 쓴다. `DIM|NUM|TEXT|标注|尺寸|编号|轴号…`가 붙은 레이어(치수·번호)는 뺀다.
   - **`DOTE`가 있으면 그것만 쓴다.** 天正 관례상 `DOTE` = 축선이고, `AXIS` = 축 번호 원과 치수선이다. `AXIS`의 긴 치수선을 축선으로 읽으면 안 된다.
   - 사용자가 레이어를 직접 고를 수 있다(`GridOptions.layers`).
4. **회전**: 축선의 길이 가중 지배 방향을 구해서 풀어 준다.
5. **축척**(`drawingScale.ts`, StruXureAI): 치수 문자 체인으로 "기하 ÷ 참값"을 구한다. 중국 시공도는 2배로 그리는 일이 흔하다(PKPM/YJK 출도). 흔한 값(1, 2, 2.5, 4, 5, 10)일 때만 보정한다.
6. **단위**: `$INSUNITS`(4 mm, 5 cm, 6 m)를 쓴다. 0이면 축 간격 중앙값으로 추정하고(`unit_guessed`), 사용자 확인이 필요하다.
7. **묶기**: 같은 위치 ±5 mm(실제 크기)의 선을 축 하나로 묶는다. 1.5 m보다 짧은 선은 버린다.
8. **주축/부분**: 직교 방향 축망 범위의 90% 이상을 지나면 주축이다.
9. **번호**
   - 축선 끝 너머의 원(반지름 150~1500 mm) 안 글자를 쓴다. 원이 없으면 축선 연장선 위의 글자를 쓴다.
   - 번호가 없거나 겹치면 자동 번호를 매긴다. 세로축은 1, 2, 3…, 가로축은 A, B, C…이고, I·O·Z는 쓰지 않는다(GB/T 50001).
   - 부분 축선은 `1/2`(2축 뒤 첫 부분 축선) 식이다.

## 2-1. 치수 우선 스팬과 DXF 모드 (v1.4.1)

- **스팬은 치수 표기 값을 우선한다**(`snapGrid`). 스팬마다 그 구간을 재는 치수를 찾는다.
  1. `DIMENSION`: 측정점(13·14)이 스팬 양 끝과 ±max(50 mm, 1 %) 안에 있는 것. 표시 값은 치수 블록(`*D…`) 안의 글자에서 읽는다. 라이브러리가 그룹 1·42를 읽지 않기 때문이다.
  2. 분해된 치수 글자(숫자 TEXT): 스팬 가운데 ±20 %에 있고 값이 스팬과 가까운 것.
- **판정:**
  - 선 좌표와 max(30 mm, 2 %) 안이면 치수 값을 쓴다(`dim`).
  - 구간이 맞는 치수인데 그보다 많이 다르면 선 좌표를 쓰고 불일치로 표시한다(`conflict`, 빨강).
  - 치수가 없으면 선 좌표를 1 mm로 반올림해 쓴다(`geom`, 주황).
  - 좌표는 첫 격자선부터 스팬을 더해 다시 만든다.
- **시작 화면:** [DXF 평면도로 시작] / [새 프레임](직접 그리기) / [Gen 예제].
  - DXF로 시작하면 축망 단계는 가져오기 화면만 보여 준다. [직접 그리기로 바꾸기]로 전환할 수 있다.
  - 적용하면 **스팬 잠금** 상태가 된다(`F.cad`, 화면 상태라 스펙에는 없음).
    - 숨김: 스팬 입력, 형상 프리셋, 평면 치수 클릭 편집.
    - 남김: 패널 빼기, 삼각 패널, 축 번호.
    - 평면에 DXF 밑그림(축·기둥·벽 레이어 선)과 스팬 출처 색을 보여 준다.
  - [스팬 직접 수정]으로 풀고, [DXF 값으로 되돌리기]로 가져온 값(스팬·패널·축 번호)에 다시 잠근다.

## 3. 사용자 안내 — 天正·中望에서 DXF 만들기

화면 문구와 도움말의 원본이다. ⚠️는 실제 프로그램으로 아직 확인하지 않은 부분이다(샘플 DXF로 확인 필요).

### 天正建筑 (TArch)

- 天正의 축망·기둥·벽은 **天正 전용 객체**다. 그대로 DXF로 저장하면 다른 프로그램에서는 비어 보이거나 프록시 객체로 남는다. 축선을 못 읽는 가장 흔한 원인이다.
- 순서:
  1. 天正에서 **文件布图 → 图形导出**를 실행하고, 저장 형식으로 **天正3**를 고른다. 전용 객체가 일반 선·글자로 바뀐다. ⚠️ 메뉴 이름·위치는 天正 버전에 따라 다를 수 있다.
  2. 내보낸 도면을 CAD(AutoCAD 또는 中望CAD)에서 열고 **另存为 → DXF**로 저장한다. 버전은 2007 이상을 권한다.
- 레이어는 바꾸지 않아도 된다. 앱이 `DOTE`(축선)와 `AXIS`(축 번호)를 알아본다.

### 中望CAD (ZWCAD)

- AutoCAD와 같은 방식이다. **文件 → 另存为**에서 파일 형식을 **DXF**(2007 이상 권장)로 고른다.
- 中望 건축판(中望CAD建筑版)의 전용 객체도 天正과 같은 문제가 있을 수 있다. 그럴 때는 평면을 새 도면에 복사해 **分解(EXPLODE)**한 뒤 저장한다. ⚠️ 中望 건축판에 天正3 같은 내보내기 기능이 있는지는 미확인이다.

### 공통 요령

- **한 파일에 평면이 여러 장 있으면** 가져올 층의 평면만 새 도면에 복사해 저장하는 것이 가장 확실하다. 앱의 영역 선택(예정)으로도 고를 수 있다. 장마다 축척이 다를 수 있다.
- 축선이 끊겨 그려져 있어도 같은 위치면 하나로 묶인다.
- 단위가 지정되지 않은 도면(`$INSUNITS = 0`)은 축 간격으로 mm·cm·m를 추정한다. 가져온 스팬 길이를 꼭 확인한다.

## 4. 검증

- 합성 DXF(`verify-cad-grid.ts`): 天正 레이어(DOTE/AXIS·치수선), 30° 회전, 2배 출도, m 단위(지정·추정), GBK 레이어 이름 `轴线`, 부분 축선 반영, 자동 번호(I·O 제외).
- 실제 도면: StruXureAI `dwg sample/zg test2.dxf`(探索者 TSSD 관례 `AXIS`/`AXIS_NUM`/`AXIS_DIM`, 버블이 분해되어 번호는 기본값 'A' → 자동 번호).
  - 결과: 주축 X `[0, 8.4, 16.8, 25.2, 33.6]`, Y `[0, 8.4, 18.65, 27.05]` m, 부분 축선 5개.
  - 로컬 `samples/cad/`(gitignore)에 있을 때만 검사한다.
- **필요한 것**: 天正(图形导出 후 DXF)과 中望 원본 DXF 각 1~2장. 지금 실제 DXF는 1장뿐이다. 天正 전용 객체를 그대로 저장한 DXF(실패 사례)도 있으면 안내 문구를 확인할 수 있다.

   - 기둥이 없거나 모든 패널이 빠지면 제안하지 않는다. 사선 변(`cuts`)은 제안하지 않는다.
   - `zg test2.dxf`: 기둥 18개, 코어 교점 2곳은 벽으로 지지 → 빼는 패널 없음.
