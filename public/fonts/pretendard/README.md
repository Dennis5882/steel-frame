# Pretendard Variable 1.3.9

Official dynamic WOFF2 subsets, served by this app. End users do not install a font.
The browser requests only subsets needed for the text on screen. No external
Pretendard CDN is required.

- Source: https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/web/variable
- Files: `pretendardvariable-dynamic-subset.css` and its 92 `woff2-dynamic-subset/` assets
- License: SIL Open Font License 1.1, included as `LICENSE.txt`
- Copyright (c) 2021 Kil Hyung-jin, with Reserved Font Name Pretendard.

Files are copied without changes from the pinned release. `../ui-fonts.css`
defines the language stacks shared by the app and exported HTML reports.
PDF reports continue to embed the regional Noto Sans CJK subsets.
